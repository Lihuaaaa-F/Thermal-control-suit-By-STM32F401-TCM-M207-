# G0 试验日志（2026-10-26）——调温服 LVGL 迁移 v12.5 G0 模拟器底座

纪要：按 v12.5 第二章方法论记录 G0 全部"试错不算失败"事件。产物树 `D:\Espressif\ws\tcs_lvgl`。

## E1 LVGL 源获取：git clone 两连断 → codeload tarball 单流
- 现象：`git clone --depth 1 --branch v9.6.0` 经 Clash TUN 两次中断（early EOF / sideband disconnect），
  复试 7 分钟仅 12MB。
- 假设：代理对 git 的多 pack 流不稳，单流 HTTP 更稳。
- 实验：`curl -L --retry 5 codeload.github.com/.../tar.gz/refs/tags/v9.6.0`（预期：一次拉完 ~106MB）。
- 结果：成功（106.3MB，sha256 b20ee3acc1bba13c…）。tag→commit 用 GitHub API 实查：
  v9.6.0 = 80ca777e37a2b176770726a02e07a6fb79ef0b39。
- 结论：**vendoring 无 .git 时版本锁改用「版本宏+源码树 sha256+tarball sha256」三重锁**
  （tools/verify_locks.sh，TL-16 前身），比裸 git rev 更硬。知识已入 README 附录 A。

## E2 Git Bash → cmd 引号被吞 → build.cmd 包装
- 现象：`cmd //c "\"...VsDevCmd.bat\" && ..."` 报"不是内部或外部命令"。
- 结论：MSYS 路径转换吃引号；**一律走 .bat 包装文件**（build.cmd），bash 只 `cmd //c build.cmd`。

## E3 benchmark CSV 无场景数据 → LV_USE_PERF_MONITOR 未开
- 现象：bench 跑完 8932 帧，stdout 只有表头无场景行（预期：16 场景 FPS/耗时）。
- 假设链（一次一变量）：①日志级别滤掉→查 lv_log.h/lv_log.c：LV_LOG 无级别门，否；
  ②打印在 summary_display 内而设 end_cb 后调用方负责→修 main.c 调
  lv_demo_benchmark_summary_display()，仍无场景行；③读打印循环：场景行仅当
  `measurement_cnt != 0` → 测量源=perf monitor，默认关。
- 实验：lv_conf.h 加 `LV_USE_SYSMON 1` + `LV_USE_PERF_MONITOR 1`（预期：CSV 出全 16 场景）。
- 结果：PASS（All scenes avg 38 FPS，模拟器参考值）。
- 结论：**v9.6 benchmark 的 FPS/render/flush 测量依赖 perf monitor**；另注意
  v9.6 API：设 end_cb 后 summary 显示与 CSV 打印责任在调用方（lv_demo_benchmark.c:666-671）。

- 产物：third_party/fonts/msyh_face0.ttf（Microsoft YaHei regular）。

## E6 字形 ofs_y 语义定案（禁猜，读源码）
- 依 lv_draw_label.c:671：`letter_top = pos_y + (line_height - base_line) - box_h - ofs_y`，
  与 montserrat_14 实数据反推一致（ofs_y 正=墨底高于基线）。
- 轨道 a 全盒字形取 ofs_y=0/box=24/base_line=0 → 整盒从 label 顶 blit，与现屏
  f_cell_draw(x,y,24,24) 逐像素同语义。实测双轨字底相对各自基线标记均 -2px（相对差 0px）。

## E7 点阵 24px 表原生无 ℃（找茬 Z1 根因）
- 现象：轨 A 渲染 ℃ 为占位框。查 cp 表：℃(U+2103) 只在 32px 固定集（gen_font_cn.py 设计如此，
  现屏同 limitation）。
- 修复：轨道 a 生成 tcs_font_lv32（138 字）作 tcs_font_lv24 的 **fallback**；复验 ℃ 正常+相对
  基线 -2px 与本轨一致（跨字号墨底浮离 ~2px 记 Z4，G1 用真实需求驱动校正）。
- 教训：混排串设计前先对码表白名单，font_audit 前置而非事后。
