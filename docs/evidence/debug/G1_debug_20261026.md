# G1 试验日志（2026-10-26）——P0/P1 复刻与字体轨

## E1 比例字库斜切（首版渲染"25.1"变条纹块）
- 现象：96px/20px 比例宽字体渲染为斜切条纹；24/32 全盒字体正常。
- 假设→实验：读 `lv_font_fmt_txt.c:121` `stride_in = g_dsc->stride`；**stride=0 语义为
  「行间比特连续」**（注释 "without a stride the rows are packed continuously"）。全盒 24/32
  宽=24/32bit 恰整除 8 → 无碰撞；96px 行 61bit（8B 含 3bit 填充）、20px 行尾填充 → 被斜读。
- 修复：字体 dsc 统一 `.stride = 1`（行首字节对齐）。回归：三字重全帧与 fb 逐像素对齐。
- 教训（入台账）：**LVGL A1 位图行对齐不是默认行为，必须显式 stride**。

## E2 perf 角标污染取证帧
- 现象：p0/p1 帧右下角叠加 "38 FPS, 0% CPU"。
- 修复：页面模式 `lv_obj_add_flag(lv_layer_sys(), LV_OBJ_FLAG_HIDDEN)`（LV_USE_PERF_MONITOR
  为 benchmark 保留）。回归：8 态帧零叠加。

## E3 800 轮页面重建段错误（资源泄漏）
- 现象：`sim cycle 800` 段错误；内存 used 10KB→4809KB（≈48KB/轮）。
- 假设：每种状态重建的 sprite（点/三角/遮罩 2.4MB）dsc+data 只分配不释放；estop 遮罩
  100 轮×2.4MB=240MB > 64MB → lv_malloc 失败未判空。
- 实验：①补分配判空；②图像对象挂 LV_EVENT_DELETE 释放 dsc+data。
- 结果：**cycle 3000 两次连跑 used 恒定 49152B / frag 1%**（平台期=字体字形缓存）。
- 教训：**sprite 资源必须绑对象生命周期**；此模式即 TL-2（页面建删零增长）的 L2 预演。

## E4 空 glyph_dsc 触发 MSVC C1001
- 现象：重构后字体 .c 全量 ICE。根因：emit_lv_font 全盒路径未生成描述符 → 空数组初始化。
- 修复：全盒模式自动生成 dsc（bitmap_index=idx*per、adv=size<<4、box=size）。
- 教训：生成器重构后必须全量重生成+全构建（打勾≠跑过）。

## E5 fb 基线版本陈旧（非缺陷）
- 证据：fb 基线链路点 y=26（现行常量 31）、时钟自然步进（现行 12px 制表位）、新鲜点
  (304,168)（现行 (455,173)）——分别早于 D4 点锚定与 D3 表宽修复。
- 处置：以现行固件代码+定稿 mock 为准；VL-16 判定"有意差异（基线陈旧）"，gap 不修代码。

## E6 fb 文字逐像素一致验证
- 方法：墨迹 bbox 双边对比（手动/设定/已停止/体温/M207/ESP/°C）+ 全帧 mean 0.30。
- 结论：点阵轨复刻达逐像素级；差异只剩点锚定/圆角引擎边缘。
