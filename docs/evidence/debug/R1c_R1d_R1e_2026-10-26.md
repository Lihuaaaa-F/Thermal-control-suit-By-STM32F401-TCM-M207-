## 附带工程事实

- **CPU 占用（首份 vTaskGetRunTimeStats，常态构建，WiFi+web+m207+console 全活动）**：IDLE0=99%/IDLE1=98% → 网络核 ~2%（预算 <70%）、控制核 ~2%（预算 <30%）；全部任务 <1%。
- **栈高水位（vTaskList）**：tmp117_svc 2028B / ctrl_svc 2072B / m207_svc 1252B / wifi 4164B —— 第八章 ≥1KB 红线全过（tmp117/ctrl 曾 840/1044，涨栈 4096 后达标）。
- **boot 瞬态签名（absent 体温传感器）**：上电 → healthy 短暂为真 → UNARMED→ARMED（~4.0s）→ 10 错 LOST+ALM_BODY_SENSOR（~4.5s）→ 驻 LOST_ALARM。H743 同源行为；装件后自然消失。
- **SAFE 重驱语义**：SAFE 期 control 每 500ms 重发 TCSW=0×2（H743 同源防御性重驱），m207 vok 持续增长、verify OK 日志拍 tick_max 峰值 ~2.1ms=控制台 IO（计算路径稳态 202µs）。R2 快照带宽评估时计入。
- **console 全链穿透**：`p set tc1_set 30` → param_set → hook → 50ms 队列 → 真模块 `verify OK ch=1 TCADJTEMP=30.000`（E-03 型 L3 证据白送）。
- **真实副作用**：E-21 期间真模块 TC1 TCADJTEMP 被 FSM 写为 15.0/45.0 往复、TCSW=1/0（TEC 无负载=电无害）；结束 mode=手动+TCSW=0（F9）。模块 RAM 值断电即回到 EEPROM 存档。
