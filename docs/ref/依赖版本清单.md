## tree hash 重录协议（红队 W9 建议 7 采纳）

Drivers/qr 树被合法改动（W1 重写 ft5446 所在 Core/Src 不动 Drivers；W4.2 vendor RTT 入 App/rtt 不动 qr）时：改动 commit 的关单台账行**必须**携带新 `git rev-parse HEAD:<路径>` 值并同步本清单对应行；未同步=清单锁失效即 W9 门禁红。
