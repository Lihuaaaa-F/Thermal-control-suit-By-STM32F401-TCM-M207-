# chart 页规格草案 v0.1（G2 产出；D-L13 增补预稿，待 G3 裁决/用户终裁）

定位：温控曲线页（记 **P2**）——30min 双通道水温曲线，语义对齐网页端 canvas 曲线。
本稿=若 chart 页入正式 UI 时写入《现行UI规范》的增量规格；G2 原型据此实现并已出帧取证。

## 1. 布局（1024×600；8px 网格；token 见 §3）

| 元素 | rect | 规格 |
|---|---|---|
| 标题 | 32,16 | 「温控曲线 · 近30min」32px tx |
| 图例 | 右侧 700..956,22 | ●贴身水箱（tx/24px）●环境水箱（tx2/24px）；红竖条+「阈值」红 24px |
| 曲线卡 | 32,72,960,456 | 卡片规格=ui_card（卡底+1px 描边+2px 底饰线，圆角 8） |

## 2. 数据语义（对齐网页端 canvas）

- 窗口 **30min**，采样 **30s**，点数 **60**（环形缓冲；窗口滚动）。
- 双序列：贴身水箱（tx 灰阶）、环境水箱（tx2 灰阶）。**数据层零蓝**（UI 规范 §1.2）。
- 量程固定 **-10..50°C**；**越界值顶格显示**（clamp 到绘图区上/下缘），是否加"越界"红字提示=**待 G3 裁决**（原型未加）。
- 单点态：仅 1 点（线画不出时的退化）；空态=无点。
- 阈值线 45°C 与报警表 ALM_OVERTEMP 同源参数（tc 上限），非独立魔法数。
- 刷新：页面可见时 1Hz 追加；离页停止采集刷新（省预算）；重入补历史环形缓冲（数据层在 control 采样侧，UI 只读）。

## 3. token 映射（UL=ui_layout.h）

背景 bg / 卡 card / 描边 border / 标题 tx / 副文本图例 tx2 / 阈值 & 报警语义 red；
曲线色=tx、tx2（**禁蓝**）；选中/悬停交互色暂无（页面只读，无手势）。

## 4. 轻交互与可达性

- 页面只读：**无滑动手势需求**（与网页端 canvas 只读一致）；返回钮 ≥64px 高（规范 §4）。
- 状态常驻：链路线/报警横幅不在本页（本页为二级页，顶栏只留返回+标题；报警发生时由
  G5 统一策略决定是否保留横幅——**待 G3 裁决**）。

## 5. G2 原型与规格差异（诚实记录）

- 原型实现了 §1/§2/§3 主结构；返回钮/报警横幅策略未实现（原型无导航栈）；
- 轴标签与量程线对齐为近似（标签基线 vs 网格线差 ≤4px，已入找茬观察项）；
- 原型数据为合成波形，真机数据源在 G5 接入（control 采样环形缓冲）。

## 6. 若入正式 UI 的后续动作（D-L13）

1. G3 用户裁定「chart 页是否入正式 UI」（任务书 G3 ③④）；
2. 入=按本稿增补《现行UI规范》为 P2 章节（且排 v11.3 R6 终验后，D-L14③）；
3. 不入=本稿归档，原型作为增量价值证据留档。
