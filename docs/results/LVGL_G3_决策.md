## §3 UX 使用逻辑预演（U-1/U-2/G2 手势）

- P0/P1 全入口×出口零死路（U-1）；急停任意态可达（双通道+屏入口兜底层设计，G4 实测）。
- 手势语义实测：拖动跟手≤1 帧、长按首发 400ms/连发 150ms、滚轮滚动+选中态、页切换 300ms 滑动无撕裂。
- 反馈及时性：press→首视觉变化 **3 刷新帧 / 0-16ms（参考）**，≤6 帧门 ✓。
- **待用户裁决的 UX 分支**（规格草案 §2/§5）：越界值是否加"越界"红字提示；报警横幅是否驻留 chart 二级页。

  → G5 触摸会话需复核去抖窗与连发节拍的相对余量。
