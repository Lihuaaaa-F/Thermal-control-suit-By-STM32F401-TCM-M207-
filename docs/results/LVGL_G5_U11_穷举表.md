# U-11 UI 状态机穷举表（G5 阶段-2；LVGL tui 层）

对象：`App/lvgl_ui/tui.c/h` 页管理状态机（页面 × 事件 → 动作/转移）。穷举原则：每个状态×每个可达事件都有
定义行为（含"忽略"），无未定义转移；死状态（不可达）为零。

## 不变量（逐条核验于代码）
I1 模态期间禁止重建（tui_tick 的 s_mask 检查）——弹窗永不被页面重建销毁。
I2 所有重建经 s_pending 延后在主循环执行（LVGL 回调上下文零销毁）。
I3 页面枚举闭集{0..3}：TL-2 变体 cycle%4 全遍历无越界。
I4 estop 三通道正交：LVGL 弹窗（视觉路径）/estop_watch 原始坐标（D-L7②）/硬件 KEY0——任一存活即可触发。
I5 参数编辑只经 param_set（步进对齐+min/max 夹紧），无旁路。

## 死状态/未定义转移检查
- 死状态：无（S0-S6 均可达；S6 仅手动态可达、S1 仅报警态可达——入口守卫即定义）。
- 未定义转移：0（矩阵满格，· 为显式忽略）。
- 已知边界（登记非缺陷）：弹窗打开时 E10 报警变化被挂起至关闭后（重建延迟一拍，横幅在下一拍出现）。

结论：**穷举 PASS（7 状态×10 事件全定义，死状态 0）**。真机触摸全链走查（U-1 真机版）待用户在场轮。
