# R0 迁移设计书（第七阶段·架构 v2，v10.8 授权先行）

> 纯设计文档不动代码。依据：架构 v2 定案（H743=纯屏终端 / ESP32-S3=主控），任务书第十章。硬门禁：迁移前后 UI 基准帧 diff=0。

## ① 显示快照 msg 消息格式表

| 字段 | 编码 | 频率 | 全量/增量 |
|---|---|---|---|
| tc1_act/tc2_act | f32 ×2 | 10Hz 全量+变化即推增量 | 全量帧 0x20 `TCS_SNAPSHOT`（复用 0x10 STATUS 扩展：追加 set 值/lit 新鲜度/POST 六态/badge 态） |
| body_temp | f32 | 同上 | 增量帧 0x21 `SNAP_DELTA`{bitmap 字段存在位+值} |
| tec1/2,fan,mode,alarm,online | u8/u16 | 变化即推 | 增量位图=现有 0x11 PARAM 泛化 |
| 版本/序列 | u32 | 1Hz 心跳携带 | — |
- 下行（H743→ESP32 请求）：复用 0x12 SET_PARAM/0x15 CMD 不变；上行新增仅 0x20/0x21 两消息（消息只加不改）。
- ARQ 500ms×3 复用；快照丢包容忍（下一周期覆盖），命令类必达不变。

## ② 断链参数表

| 参数 | 值 | 依据 |
|---|---|---|
| 心跳周期 | 200ms（快照帧即心跳） | 500ms 判定=2.5 帧丢失 |
| 判定窗 | 500ms 无任何下行帧→断链 | 沿用现 comm 超时口径 |
| ESP32 自主 SAFE | 停双 TEC+风扇安全侧（全开）+本机报警态 | 双保险第二腿 |
| H743 屏表现 | 缓存末值+失联横幅（现有） | 不清屏不闪 |
| 恢复策略 | 复插→快照重同步；若断链期 ESP32 曾 SAFE→保持 SAFE 按安全侧，需人工 ack | 安全侧粘滞 |

## ③ 任务与核分配表（ESP32-S3 双核）

| 核 | 任务 | 说明 |
|---|---|---|
| Core 0 | WiFi AP+httpd+WS+OTA、链路 ARQ、显示快照发送 | 网络钉核 0（现状 20-35% 单核，余量充足） |
| Core 1 | control FSM（500ms）、param_registry、M207 服务（50ms 队列+读回）、TMP117 采集、esp_task_wdt | 控制钉核 1；与网络互不挤占 |

## ④ 移植文件级清单

| 动作 | 文件 | 备注 |
|---|---|---|
| 搬运 | param_registry.c/h | 去 EEPROM 钩子→NVS 钩子（接口不变） |
| 搬运 | control.c/h | 原样（ops 注入不变） |
| 搬运 | m207 帧构造/解析纯函数 + m207_adv 语义 | 传输层按 ESP32 UART 重接（R5） |
| 重写 | HAL 层：eeprom→nvs_store、tmp117 i2c→ESP32 i2c 驱动、fan gpio | 引脚见 ⑤ |
| 重写 | console（邮箱→USB CDC/jtag 控制台）、post（传感侧） | 触摸 POST 项留 H743 |
| 删除 | H743 侧 m207.c/tmp117.c/control.c/eeprom/fan 全部执行路径 | 触摸整治与 UI 成果全保留（tcs_ui/ft5446/ltdc/console 不动） |
