### 本阶段新坐实缺陷与修复（找茬 8-10；全记录 `docs/evidence/debug/R1b_2026-10-26.md` E7-E9）

8.【坐实+修复】**realprobe 帧缺 `\r`→模块回 errcode=2**：同一参数 `TCADJTEMP?` 带 `\r` 回 `=26.00`、不带回 `=2`——此固件对无终结符命令按帧间隙超时解析回 2，正典 §1"静默忽略"不成立（勘误候选）。连带坐实应答时序错位误归属（=2 落进轮询等待窗被判 SENSOR-OPEN→翻转 5 轮）。修法：send_raw API 统一补 `\r`+断线 3 连去抖+unexpected 补日志。
9.【坐实+修复】**ERRCODE 应答计为通信失败**（轮询等待期 errcode 一律 s_fail++→可能 5 败假离线）：轴分离修复——CMD:REPLY=链路活证据，永不计 comm fail；errcode=2+等温度=传感器断线候选（去抖 3 次坐实，F6）；其余留痕 unexpected。
10.【排除+勘误】V-5 注入回码与正典偏差：未知模块回 2（正典 0）——C2 裁定以真机为准；errcode=5 无安全触发法挂账；COMPUSHLIST 格式（.REG+_类型后缀）与正典未记载→补注。
