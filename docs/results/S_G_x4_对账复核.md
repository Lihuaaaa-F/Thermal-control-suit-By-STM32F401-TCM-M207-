## 五、验证与风险

- **本批次未改任何固件代码、工具脚本、测试**（`git status` 仅 docs 与本文件），因此未跑构建矩阵与
  `tests/run_all.sh`：无编译输入变化，门禁结果与基座 `b61c193` 相同（本分支从 `fix/s-u-int2` 快进，无代码差异）。
- 本批次做的"验证"是只读核对：`git grep -n`、`sed -n`、`git log -S`、`git cat-file -e`、以及一个只读的
  key 对照脚本（读注册表 + 正典，不写文件）。
- **风险点**：
  1. X04-F-05 判"已实施待真机"是按用户既定口径记的；严格说交付档（非 DIAG/SIM）**没有任何**运行时观测点，
     关单条件里的"报警位/SAFE 接线"未做。读者不要把它理解成"交付档已有零检测"。
  2. X05-F-06 判"已修未记"含一个残留（`cmake:14` 兜底 PATHS）。它只是搜索路径、不进镜像，但严格的可复现
     结论应以 `bash tools/build_matrix.sh --twice` 的原样输出为准——本批次没重跑。
  3. 抽样 12/46 只覆盖 26%。位置漂移率 7/12（58%）说明**整本台账的 file:line 都可能过时**；判定可信、
     位置不可直接引用。若后续有人按台账位置改代码，需先 `git grep` 定位。
