**口径**
- 状态词：`未做` / `进行` / `已做待核` / `关单` / `挂账[依赖]`。
- **关单硬条件**（每条都要满足）：① 判别性测试（把修复回滚或改坏，测试必须变红）**或**真机数字证据；② 证据文件落盘并在本表写路径；③ 独立复核（不是我自查）；④ 台账 CSV 与 `docs/台账.md` 同步。
  - 2026-11-24 晚追加一条口径：**"关单"还要求证据是在最终代码上取的**。规则或固件变了，旧证据只算"历史证据"，要重取（例如急停入口的真机矩阵是在规则 v1、带钩子的旧交付档上取的）。
- 证据等级沿用审查口径：L0 纯读码 / L1 代码+全量 grep / L2 构建与静态 / L3 主机可执行复现 / L4 目标板观测。
- 结论必须带数字与 `file:line`；禁语沿用 `_support/_REVIEW_KIT.md` §0.5。
- **TEC 边界**：不做任何驱动 TEC 制冷/制热、加热触发超温、依赖 TEC 带载的实测。急停、确认、SAFE 这类**只做关断方向**的操作不算 TEC 驱动实测（且当前 TEC 从未带载）。凡出口门里需要 TEC 实测的子项，记 `挂账[TEC 实测]`，其余子项做满。
- **需用户动作的项**：写明等待条件，备好"一条命令出判定"的脚本，其余工作继续，不停等。
- 设备（探针/串口）只由主会话操作；只读子代理一律不碰设备、不改任何工作区。
