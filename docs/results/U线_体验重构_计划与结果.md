## 0. 用户指令与硬约束

**用户指令（2026-11-24 凌晨，原话要点）**
1. "自动恢复逻辑极差，很不符合现实使用场景；每个页面的显示没有仔细审核过（主页的『停止』和前面那个圈不居中）；点击恢复后 M207 和 ESP32 的连接状态不对、更新不及时、显示不明显；代码可维护性、可读性差；用起来很多功能都难受。"
2. "ESP32 的网页端很久没更新……仔细优化，每个功能都能用而且好用，未来我们要使用这个网页。"
3. "开分支直接高质量更改完；务必先写详细计划，再严格按计划执行；优化必须有用，不是表面功夫；明早验收。"
4. "有什么提高代码质量的建议？哪些部分需要修改或重写？"

**硬约束**
- **TEC 相关实测禁止**（沿用 S 线用户原话"和 TEC 有关的实测请你先不要做，比较危险"）。今晚真机只做：显示/导航/状态呈现、关断方向（急停、确认、SAFE）。不切自动模式带载、不触发超温。
- 不碰 `D:\Espressif\ws\tcs-sline`（S 线未提交实现）与其工作树；本线独立工作树 `D:\Espressif\ws\tcs-ux`。
- S 线里用户已确认的两条决定并入本线设计：首页按住急停键 ≥0.6s 无弹窗 → 直接急停（仅首页）；急停后急停键变灰，解除后回红。
- 关单硬条件：① 判别性测试或真机数字证据；② 证据路径写进本表；③ 自查 + 独立复核；④ 台账同步。

**证据等级**：L0 读码 / L1 代码+全库 grep / L2 构建与静态（nm、反汇编）/ L3 主机可执行复现 / L4 目标板观测（探针读帧缓冲截图、探针读 RAM、ESP32 控制台）。
**环境事实**：本机唯一出口是 WLAN（`uav123-5G`），且 aTrust 拦 PC→设备 AP 的 TCP —— **本机不能连设备热点做网页实测**（会断网杀会话，也连不通）。网页实测 = 主机 mock（同一份前端文件 + 同一 WS 契约）+ 真实浏览器；固件侧 = 主机契约测试 + 真机冒烟。

## 2. 设计

### 2.1 连接状态模型（H743，纯逻辑可单测）

新增 `App/lvgl_ui/ui_model.[ch]`（零 LVGL/HAL 依赖，`tests/test_ui_model.c` 主机跑）。

```c
typedef struct { uint8_t link_up, have_data, m207, body, sens_open; uint16_t alarm; } ui_link_t;
typedef enum { UI_SRC_OK, UI_SRC_LOST, UI_SRC_UNKNOWN } ui_src_t;
/* link_up = 距最近一帧快照 ≤ UI_LINK_STALE_MS(500)。link_down 时三个源一律 UNKNOWN（不能拿陈旧值冒充）。 */
ui_src_t ui_src_m207(const ui_link_t*);  ui_src_t ui_src_body(const ui_link_t*);
```

主页顶栏右侧改**常驻状态条**（任何报警下都在）：两枚胶囊 `主控 ●已连接/●连接断开 Ns`、`模块 ●在线/●失联/●未知`。颜色：绿=正常，黄=模块失联（数据仍实时），红=主控断开。
主控断开时：数值转灰、数字保留（标注"N 秒前"），页面顶部出红色本地横幅"与主控失去联系"。
刷新节拍 500ms → **200ms**（就地改文本，同文不重绘，成本可忽略）。

### 2.2 恢复策略（目标行为表）

| 故障源 | 进入 | 退出 | 退出后 | 屏幕横幅 |
|---|---|---|---|---|
| 急停 | 立即：TEC 全关 + 风扇全速 + 切手动 + 锁存 | **仅人工解除**（其余源须健康） | 手动、输出全关、风扇回故障前状态 | 红："急停已触发 · 点击解除" |
| 超温 >48°C | 立即：TEC 全关 + 风扇全速 + 锁存 | **仅人工解除**且水温 ≤48°C | 模式不变；自动模式状态机重新评估 | 红 |
| 体温传感器失联 | 连续 10 次采样失败（1s）；已布防则进 SAFE | 源健康连续 2s **自动** | 风扇 + 手动 TEC2 **恢复到故障前状态**；自动模式状态机接管 | 黄："…接好后自动恢复" |
| 模块通信中断 / 探头断线 | 5 连败（≈2.5s）/ 3 次 errcode=2；SAFE | 同上 | 风扇恢复；**TEC 输出不自动重开**（模块侧状态未知） | 黄 |
| 屏链路断 | >500ms 无快照 | 收到快照即恢复 | — | 红色本地横幅 |

ESP32 固件侧改动：
- **E1 控制节拍 500ms → 100ms**（`control_service.c`）：故障发现、自愈计时、退出 SAFE 都变成 100ms 粒度；SAFE 期间的 `TCSW=0` 重申与参数落盘保持 500ms 节流（不给模块加流量）。布防步进随之回到设计口径（修 B4）。
- **E2 退出 SAFE 复原**（`control.c`）：进 SAFE 时记 `fan_before_safe`/`tec2_before_safe`；退出时风扇复原；若本次锁存**只含 BODY_LOST** 且是自愈退出，TEC2 复原。急停/超温/模块类不复原 TEC。
- **E3 确认回执可判定**：`tcs_alarm_ack` 返回"清掉了什么/还剩什么"，0x90 ACK 的 `ret` 字段带回**仍未恢复的源位图**；屏幕据此提示。

H743 侧：
- **S-Banner 分级**：需要人工解除的（急停/超温）文案"点击解除"；自动恢复的（三类通信/探头）文案"…接好后自动恢复"，点击给提示而不是静默无反应。
- **S-确认反馈**：点横幅 → 立刻发 cmd 9 → 等 ACK（≤200ms）：全清 → 提示"已恢复"；有残留 → 提示"××仍失联，恢复后自动继续"。不再出现"闪一下又回来"（本地不再抢先清位，以对端 ACK/快照为准）。
- **S-解除急停提示**："急停已解除 · 当前手动模式，点『切自动』恢复自动温控"（安全规范：急停复位后不自动重启，需单独的启动指令——此点不改）。
- **S-Toast**：底部浮动提示，2.5s 自动消失。

### 2.3 页面框架（H743）

- **就地更新**替代"状态一变整页重建"：每页持有动态控件句柄，`update()` 只改变化的文字/颜色/位置（去 A5、B5 的整页重绘）。

### 2.6 网页控制台（ESP32 `tcs_web`）

**固件侧**
- W1 状态 JSON 取**本端权威** `g_tcs + control_state + 锁存 + 布防 + 屏链路活性 + 运行时长/复位原因/堆`，不再绕屏幕；屏幕断连时网页照常工作（另给 `screen:0` 标志）。
- W2 注册表 JSON 取本端参数表（权威），不再取屏幕 0x14 缓存。
- W3 请求-响应带 `ref` 关联（替代"3 秒内同 id 即认为是自己的回显"的猜测，`websocket.c:289-291`）。
- W4 事件日志：服务端对状态做差分，生成带时间戳的事件（急停/超温/传感器掉线与恢复/模块离线回线/进退出 SAFE/模式/TEC/风扇/屏链路/改参），环形缓冲 50 条，连上先推历史。
- W5 推送：500ms 周期 + 变化即推。

**前端**（无构建步骤，原生 HTML/CSS/JS，gzip 内嵌）
- 页签：总览 / 参数 / 设备 / 日志；底部常驻急停条（所有页签）。
- 总览：三个大数值卡（两路水温 + 体温，含设定值与 TEC 状态）、执行器开关（TEC1/TEC2/风扇/自动）、报警区（分"需确认/将自动恢复"）、三线曲线（自绘 canvas，去 Chart.js 依赖）+ CSV 导出。
- 参数：常用参数（滑条 + 步进 + 直接输入 + 范围提示）；高级（M207）按功能分组折叠；保护类参数二次确认（非阻塞对话框）；只读遥测以状态卡呈现；"保存到模块"。
- 设备：热点名/密码/网址、两端固件版本、运行时长、复位原因、堆、链路统计（帧/CRC/回声）、安全锁存/布防/控制状态。
- 日志：事件时间线，可暂停/清屏。
- 断连：顶部状态条 + 半透明遮罩 + 重连倒计时；数据超过 2s 未更新标"数据过期"。

**WS 契约**（固件与前端唯一依据，`esp32/components/tcs_web/WS_PROTOCOL.md`）
- 下行 `st`：`t,seq,ts,ver,fw,tc1,tc2,body,tc1_set,tc2_set,tec1,tec2,fan,mode,state(0待机/1制冷/2制热/3安全),alarm,latch,armed,m207,body_ok,sens_open,screen,up_s,reset,heap`
- 下行 `pv`：`t,id,v,src(web|touch|console),clamped,ref,ok,err`　`ack`：`t,c,rv,ref`　`reg`：`t,list[]`　`log`：`t,list[{ts,lvl,ev,msg}]`　`err`：`t,code,msg`　`pong`：`t,ts`
- 上行 `set`：`t,id,v,ref`　`cmd`：`t,c,ref`　`ping`：`t`

### 2.7 协议增量：`MT_TCS_INFO 0x22`（ESP32→H743，免 ARQ）

载荷 = UTF-8 文本 `ssid=…\npass=…\nurl=…\nfw=…\n`（≤120B）。主控在镜像泵里每 ~6.4s 推一次。旧屏固件对未知消息号静默丢弃（前向兼容）；新屏配旧主控时连接页显示"—"。
定义只写 `protocol/tcs_proto.h`（协议唯一源）。
