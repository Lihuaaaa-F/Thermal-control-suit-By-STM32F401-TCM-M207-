## 2 为什么这样改（官方依据+被否方案）

**vendor 本体**：册 §5.2 步骤 1 要求官网包获取+版本/日期/SHA256/许可四留档——官网 zip 直链有机器人闸（curl 202 实测），改取**segger.com RTT 产品页直接背书的官方 GitHub 仓**（出处等价更强：commit hash 可锁、可复现 clone）。
被否方案：❌ 镜像站/SDK 二道贩子副本（provenance 弱）；❌ 给自研实现打补丁对齐官方（册训"能官方不自研"直接否）。

**聚合包含薄壳**：被否 ❌ 改 CMakeLists 换源条目（会把 G 线未提交的 LVGL 块裹进 W4.2 commit——纪律 4）；❌ git add -p 部分暂存（交互式不支持且脆）。聚合包含由 C 预处理器保证与独立编译单元等价（include 即原文展开，无符号改写）。

## 5 找茬记录（≥3）

3. **宏壳自噬检查（坐实）**：WriteString0 内调用官方 API 前必须 `#undef`（否则宏把定义/声明一起改写）；shim 内双 #undef+包装实现顺序=编译实证通过；vendor 源内声明被宏污染路径已由相对路径 include（vendor/SEGGER_RTT.h）+守卫隔离双重排除。
