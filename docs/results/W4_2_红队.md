**结果**：官方 INIT()（SEGGER_RTT.c:265-270）=读 `acID[0]!='S'` 判定→_DoInit()；**_DoInit 内 LOCK 计数=0**（grep 实证；官方注释自认"May only be called via INIT()"——仅防重入覆盖，非并发安全），且 _DoInit 首行 memset 整个 CB（acID 清零=窗口期另一上下文 INIT 判定必真）。工程写者：主循环 11 TU + **stm32h7xx_it.c:51 HardFault printf**（优先级 -1，BASEPRI=0x20 从不屏蔽 HardFault——1e 实证）；SysTick_Handler(:62-64) 仅 HAL_IncTick 不写 RTT。双入窗口=main.c:507 `SEGGER_RTT_Init()`（首次 _DoInit memset 中 acID 已清）恰被 HardFault 打断且后者再走 INIT→重入 _DoInit。暴露面：507 行极早（早于 ltdc_init:527 内的 DCache 启用 ltdc.c:94-95、早于外设中断使能），HardFault 与 μs 级 memset 同发概率工程可忽略；且自研版 rtt_inited 标志同样无原子保护（同构风险，非 vendor 化新引入）。
**结论**：理论竞态坐实但不可达性论证成立（→发现 R4 wont-fix 留档；制方行为差异表未覆盖此维度，并入 R1"差异表不全"证据）。
