## 5 找茬记录（≥3）

1. **"零/一"调用面的定性（诚实化）**：DMA2D 功能面 0 命中（仅 MspInit 时钟使能 1 处）——非漏查：WP-C.5 已定论弃用（硬件步进异常+18µs 开销），卡内记"弃用有据"；EXTI 0 命中=触摸用轮询模式（G_MODE=0），卡内记官方模式差异。
2. **G 线未提交区的行号时效（如实标注）**：LTDC/DMA2D/GPIO/PWR/LVGL 五卡涉 G 线工作区（ltdc.c=M 态、lvgl_port/third_party 未跟踪）——各卡显著标注"行号=工作区快照，G 线合入后重跑 ③"。
3. **官方示例路径零编造纪律**：本机无 CubeH7 例程仓（find 实探）——7 张 HAL 卡一律官方 GitHub URL 并注明"本机无"；IDF 例程则全部本地实存路径（ls 验证后才写）。两口径并存但都真。
