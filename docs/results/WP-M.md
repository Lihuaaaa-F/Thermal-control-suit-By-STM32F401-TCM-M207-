## M0 失效模式判定 + 量化（先量后动刀）

### M0⓪ 坐标映射（D1 头号嫌疑，总师预对拍实锤）
- **判定：偏移（mapping 错误）= D1 主因**。tcs 首版映射=标准字节序+X 镜像（`ft5446.c:394-402` 旧版），与 GS 验证版（2026-07-28 真手指实测"raw 直接当屏幕像素"=交换 X/Y 不镜像）差一个 90° 旋转——全部真手指落点被旋转错位，与 D1"很不灵敏几乎不可用但偶有响应"完全吻合。
- **修复**：映射收敛到唯一纯函数 `ft5446_map_raw()`（screen=(raw_y, raw_x)+clamp+仿射微调保留），`Core/Src/ft5446.c` 纯函数段 + `_Static_assert` 与 ltdc.h 一致性编译断言。
- **注入从不经过变换层的测试盲区已封死（T-13/H18）**：新增 `sim touchraw/touchrawr`（raw 级注入走完整变换链）；20 击门以 raw 坐标驱动（见 M4）。
- 真手指四角点按复核 → 复验指引卡（用户动作，指引卡 L4 产出）。

### M0 raw 日志与失效模式三分
- 工具：`touch log on|off|clear|stat|dump`（分块 CSV 导出防 TX 环溢出）+ `tools/touch_analyze.py`。
- **关键机器事实（本次普查新增）**：本屏 FT5446 空闲态 TD_STATUS 恒回 0x0F。
  - 证据 A（数据通路健康）：`touch diag` 配置寄存器回读四项全 OK（DEVIDE_MODE=0/ID_G_MODE=0/THGROUP=22/PERIODACTIVE=12 写读一致），读事务 NAK 率=0%（217,575 读/0 NAK @ soak2）→ 台账 `docs/evidence/M0_soak/`（stat 截图于 WP-M 证据 JSON）。
  - 证据 B：IC 固件版本 ver=0x0001 锁存入日志头（T-11）。
  - 推论：0x0F=该 IC 合法空闲输出（旧固件同路径静默丢弃=行为一致），驱动已按"有效无触摸"处理，不灌坏包计数、不进日志环。
- **三分回答**：漏触=无（IC 每拍应答，无 NAK 无 INT 依赖）；误杀=主因之一（旧 H1 帧级 200px 过滤跨会话惩罚真击首帧，代码路径坐实 `ft5446_ghost_jump_ok` 旧调用点）；偏移=主因之二（M0⓪ 映射 90° 旋转）。
- 幽灵会话分布：浸泡期（两次共 65min、282,752 次读）valid 触点帧=0——历史 ~1Hz 幽灵在当前台架状态未复现；会话机对"短+零位移+面积恒定"会话的拦截由 PC 单测与注入保障（M3）。
- 数据局限（诚实标注）：阈值口径=合成人类参数（真击 80-200ms 按压），**复验当天须先录 2 分钟真手指样本复核阈值**（指引卡开头，任务书 M0 双源条款）；偏移则重定并复跑 M3/M4。

### 过程事故与缺陷（不掩盖）
1. **释放样本 valid 缺陷**：raw 注入 release 最初走 n==0 早退路径 valid=0 被会话机当坏包（每 tap+1 badsample）。修复=该路径 `ev->valid=1`。复测 badsample=0。教训：注入路径的会话闭环也要逐样本验证（dbg 口 `tcs_ui_touch_debug` 因此新增）。
2. **20 击首次运行 #14 fan_off 失败一次**：同一构建下 3 次定向复现均通过、release 修复后全量重跑 20/20，判为瞬态（推测与修复前 badsample 累积态相关）；两次运行 JSON 均留档。
3. mb_console 用错 ELF（build vs build-sim）符号地址错位 → 一律 `TCS_ELF=build-sim/tcs_main.elf`。
