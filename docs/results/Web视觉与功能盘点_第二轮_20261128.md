## 2. 功能缺漏（与屏端/后端能力对照）

| ID | 级别 | 缺什么 | 依据 | 影响 |
|---|---|---|---|---|
| F1 | **P0 安全** | **切自动模式没有二次确认**：网页"模式"开关直接发 `c=6`；屏端会弹"切到自动？"确认框。 | `app.js` `SW_CMD.mode` → `send({t:'cmd',c:6})`；`tui.c tui_dlg_mode`。 | 自动模式可能立即开 TEC；误触即启动。 |
| F2 | **P0 安全/交互** | **安全态/急停锁存/数据过期时，执行器开关与参数仍可操作**（只有急停键被禁用）。屏端在安全态把方向键置灰不可点。 | `app.js` 只有 `r.steps` 边界与急停键设置 `disabled`；`05_安全态参数仍可操作.png`。 | 用户可对拒绝态下发命令，得到"未确认/拒绝"；更糟的是按过期数据操作。 |
| F3 | **P1 功能** | **没有 TEC 方向控制**：0x09/0x0A（TEC1/2 手动输出 0/1/2）flags 只有 `PF_RW\|PF_SCREEN`，网页（只显示 `PF_WEB`）看不到；网页只有开/关，不知道是制冷还是制热。 | `param_registry.c` 0x09/0x0A；`buildParams` 过滤 `flags & 4`。 | 与屏端"模式页"能力不对等；此前"网页端先不改"的决定仍然生效中。 |
| F4 | **P1 功能** | **没有 TEC 功率/电压/电流显示**：`/api/status` 字段里没有 `tec_v/i`（`web_status.c` 只有 `tec1/tec2` 布尔）。 | `web_status.c web_status_fill_json`。 | 屏端模式页有每路功率，网页只能看开关。属固件数据侧缺口。 |
| F5 | **P1 功能** | **网页没有 OTA 入口**：`/api/ota` 只在 `CONFIG_TCS_DIAG` 构建注册，交付档没有该路由；前端无上传/进度界面。 | `http_server.c` `#if CONFIG_TCS_DIAG`；`index.html` 无 ota。 | 交付设备无法从网页升级固件（只能探针/串口）。 |
| F6 | P2 | **报警只能在总览页解除**：顶栏报警条只跳转，不在当前页提供"解除"。 | `renderAlarmChip` 只 `scrollIntoView('#alarms')`。 | 在参数/日志页处理报警要切页+滚动。 |
| F7 | P2 | **数据过期（WS 在但 st 停）时不禁用控件**：值已转灰，开关/滑条仍可点。 | 无 `store.stale` 禁用逻辑。 | 可能按旧值操作。 |
| F8 | P2 | **参数没有搜索/过滤**：50+ 项，7 个折叠组；只能逐组翻。 | `buildParams` 无 filter。 | 现场找参数慢。 |
| F9 | P3 | **日志不能导出/过滤**：只有"暂停/清空视图"；`/api/log` 前端未用（历史靠 WS 首推）。 | `app.js` 无 CSV/log fetch。 | 排障记录带不走。 |
| F10 | P3 | **总览不显示屏幕链路状态**：只在设备页一行；屏链路断开后要等 3 s 急停锁存才有报警。 | `st.screen` 仅在 `DEV` 表。 | 屏线松了网页不知道。 |
| F11 | P3 | **总览没有目标温度/风扇快捷设置**：要进参数页。 | 概览无 set 控件。 | 多一步操作。 |
| F12 | P3 | **设备页 WiFi 信息只读**：SSID/密码/地址不可改，后端也无路由。 | `LINK` 只读。 | 改热点名/密码要改固件配置。 |
| F13 | P3 | **没有"恢复默认参数"**：屏端也缺（审查 M03-F-03），属共同缺口。 | 无路由/按钮。 | 参数改乱只能逐项改。 |
| F14 | P3 | **屏幕固件版本"未上报"**：协议里没有该字段，设备页永远显示"未上报"。 | `DEV` 表硬编码。 | 版本追溯不完整。 |
| F15 | P3 | **没有"全部解除"聚合按钮**：每张卡各一个"解除"，都发 `c=9`（等价）。 | `buildAlarms`。 | 多报警时要点多次。 |
| F16 | P2 | **没有与屏端"模式页"对等的页面**（两路 TEC 制冷/暂停/制热 + 功率）：网页只有执行器开关。 | 与 F3/F4 同源。 | 网页不能完成屏端的全部操作。 |

## 3. 建议顺序（等你确认后再动手）

1. **P0**：F1（切自动确认——与屏端同口径）、F2（安全态/过期禁用控件）。
2. **P1 视觉回归**：V1（48 线压扁→改成"出界时顶边标记"或允许切"看阈值/看细节"）、V2（≤340 执行器改单列或缩字号）。
3. **P1 功能**：F3/F4/F16（方向 + 功率 + 模式页，需要固件把 0x09/0x0A 加 PF_WEB、status 补 tec_v/i）、F5（OTA 入口，需决策是否只在诊断档）。
4. 其余 P2/P3 按需。
