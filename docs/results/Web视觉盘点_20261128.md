## 五、汇总（26 条）

- **P0 3 条**：报警跨页不可见、急停键无锁存态、报警排序非安全优先。
- **P1 6 条**：窄屏数值裁切、横屏底栏占 34%、单位与数值分离、参数页密度/单位位置、桌面急停变小、顶部安全区。
- **P2 8 条**：标题层级倒挂、模式开关措辞、精度不一致、提示行内标签换行、日志英文码、设备页工程口径/长值溢出、空日志无占位。
- **P3 9 条**：灰/黄对比度、黑色横线占位、连接与过期同屏、遮罩层、图表缺阈值线/端点、卡片不可点、mock 版本、overflow 被隐藏。

建议优先级：**P0 → W-04/W-05 → W-06/W-07/W-11/W-10 → 其余**。P0 全部可以在 `app.js`/`style.css`
小改完成；P1 的 W-04/W-05 需要加断点（如 ≤360 用 2+1 卡、横屏收窄底栏或把急停改窄条）。
