# 演示脚本 v1（答辩 5 分钟走查 + 触摸失灵降级预案）

## 主线（触摸可用，约 5 分钟）
1. **开机**（0:00-0:30）：上电 → 3 秒亮屏 → 自检角标扫过。台词：六项上电自检、安全布防三态。
2. **主页讲解**（0:30-1:30）：三温度仪表 + 呼吸点（数据新鲜度）+ 风扇开关。台词：注册表唯一数据源、屏/网页同为视图。
3. **触摸调参**（1:30-2:30）：调参 → 选贴身水箱 → ± 调 0.1 → 长按连发 → 保存并返回。台词：参数约束在注册表、写路径唯一。
4. **自动模式**（2:30-3:30）：切自动 → 确认框 → 演示假体温升高（`sim body 38.5`）→ 自动制冷+风扇。台词：控制闭环+FMEA 布防。
5. **急停**（3:30-4:00）：急停 → 二次确认 → TEC 全停风扇全开 → 横幅确认恢复。台词：安全自持需人工确认。
6. **网页**（4:00-5:00）：手机连 TCS-A8A1 → 网页同步展示 → 网页改参数回传屏幕 → 高级参数区（M207 模块参数，分组+危险二次确认+保存语义）→ CSV 导出。
