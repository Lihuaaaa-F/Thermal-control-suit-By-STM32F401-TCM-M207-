## 六、维护规则（承 v1，增补）

1. 新增驱动类代码前：先查 ESP-IDF 官方组件+espressif 组件库（检索记录留档），查无才自研，自研处留"查证记录"注释。
2. 单线 LED/传感器/触摸类：一律优先组件库；**禁止手搓 RMT 时序**（F1 教训）。
3. **软件 I2C bit-bang 是红线信号**：新代码禁止（F2/F3 都源于此）；存量两处按 F2（候选迁移）/F3（R4 删除）处置。
4. H743 侧"官方"=ST HAL+LVGL（官方 UI 库）；ESP32 侧=ESP-IDF+espressif 组件库。
5. 本清单随 R*n 关单更新；Q3 反抽查含本清单条目抽验。
