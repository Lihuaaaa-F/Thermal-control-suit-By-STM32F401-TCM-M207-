# 官方库对照清单（全库扫描，2026-10-26）

> 缘起：WS2812 手搓 RMT 编码器被证伪（黑帧=白），用户指令"尽量都用官方的库和例程而不是自己写"。
> 本清单=全库逐组件盘点：每处自研代码对照官方/厂商现成实现，给出**决策+理由**，长期维护。
> 范围：`esp32/`（ESP32-S3 主控）+ `project_tcs/App`（H743 屏端）。扫描日基线：commit b741ef2 之后。

## 一、结论摘要

- **已替换 1 项**：WS2812 驱动（手搓 RMT bytes 编码器 → 官方组件 `espressif/led_strip` v3.1.1）。
- **其余自研代码全部保留**，逐项理由见下表——核心判据：①官方/厂商**没有**等价物（M207 私有协议、FT5446 触摸、TMP117 寄存器逻辑、链接协议）②属于**应用业务逻辑**（参数注册表、控制状态机、布防三态机——这类没有"官方库"可言，只有 Q5 双实现纪律）③**已经在用官方库**（外设全部走 ESP-IDF 官方驱动，无一处绕过 HAL/LL 手寄存器）。
- 全库**未发现**绕过官方驱动直接操作寄存器的情况；未发现重复造官方已提供的轮子（JSON=cJSON、控制台=esp_console、WS 握手=httpd_ws、OTA=esp_ota、WiFi=esp_wifi、NVS=nvs_flash）。

## 四、风扇换脚记录（用户问询"风扇不能换一个引脚吗"→ 能，已执行）

- **旧脚**：GPIO48（接线表 v2.0 F1）——与官方 DevKitC-1 **v1.0 版板载 WS2812 RGB 共脚**，PWM 被灯珠当数据锁存随机亮色（本次"灯常亮白"的根因之一）。
- **新脚**：**GPIO42**（并行线 v2.1 已改，本扫描实测确认：FANLB 4/4 PASS 于 42；42=空闲脚，无 strapping/ADC/外设冲突，注意默认复用 MTMS/JTAG——本项目 ESP32 不用 JTAG，无影响）。
- **接线表 F1 勘误**：风扇光耦（低=开）接线 **ESP32 GPIO42**（原 48 作废）；待风扇到货按新脚接线。
- GPIO48/38 现为板载 RGB 专用：固件开机自动清黑（led_strip），console `ledblk/ledblink/ledtest` 可诊断。
- 遗留观察：并行线把风扇改到 42 后，用户仍报灯亮——待用户对本版（42 脚+开机清灯+官方驱动）做开机目视确认；若确认仍亮，则白光非 GPIO48 数据所致，转电源指示灯结论。

## 六、维护规则（长期）

1. **新增任何"驱动类"代码前，先查 ESP-IDF 官方组件与 espressif 组件库**（https://components.espressif.com）；查无才允许自研，且自研处必须留注释"查证记录"。
2. 单线 LED/传感器类一律优先组件库；外设一律官方驱动；私有协议自研属正常。
3. 本清单随 R*n 关单更新；新替换项须附"证伪记录"（像 WS2812 本例）。
