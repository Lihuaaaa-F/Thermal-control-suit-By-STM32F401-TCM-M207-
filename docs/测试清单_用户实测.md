## 0. 使用说明

- 串口：COM3 @115200（ESP32 USB 口，idf_monitor 或任意串口工具均可）。连上直接敲命令回车，提示符 `tcs`。
- 常用命令：`status`（状态一行）、`p list`、`p set <id|key> <值>`、`p save`、`mode 0|1`、`tec <1|2> <0|1>`、`fan <0-100>`、`body <°C|off>`、`estop`、`ack`、`perf`、`m207 raw <帧>`、`reset`。
- **当前板子常态**（体温传感器未装）：上电约 4.5s 后进 SAFE 驻留——`status` 显示 `state=3 fan=100% alarm=0x0001`，这是 F4 安全逻辑在正常工作，不是故障。想让板子安静：`p set commissioned 2`（强制不布防）；测 SAFE 类项目前记得 `p set commissioned 0` 恢复自动。

## D 组：已知行为说明（不是缺陷，测试时别当故障）

1. **SAFE 常驻**：体温传感器未装 → `state=3 fan=100% alarm=0x0001` 是 F4 正常保护。
2. **SAFE 期每 500ms 重发 TCSW=0×2**：防御性重驱（H743 同源语义），日志 `verify OK ... TCSW=0.000` 刷屏正常。
3. **TC1 过压锁存（STATUS bit1=0，如 253）**：无负载时 TCSW=1（U05/U06 测试会触发）→ 空载输出电压顶轨→过压保护锁存，`TCOVPSTATUS=0`；**模块断电重启清零**，保护本身工作正常（TEC 实装后不会出现）。
4. **COMPUSHLIST 输出约 30s**：数百行 `.REG` 属正常；期间控制台可继续用。
5. **ERR 灯**：模块 STATUS 有任何 0 位即亮；读 `TCERRORSTATUS` 定位——255=全正常。
