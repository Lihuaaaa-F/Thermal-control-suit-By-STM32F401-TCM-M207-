## 1. 帧语法（语法正典 v2，PDF 直接采用）

```
设定:  MODULE:PARAM=VALUE[\r]
查询:  MODULE:PARAM?[\r]
保存:  MODULE:PARAM![\r]
可选:  ...@X        地址（0-254，255=广播；默认 0；单机可省略）
       ...@X#YY    XOR 校验（必须配地址；YY=十六进制大写两字符）
帧尾:  \r（0x0D）缺失即非法不识别
```

- **大小写敏感**，命令通常全大写（PDF 4.1）。
- **命令内/前不得有空格**（PDF 4.5）。
- **数值以 ASCII 十进制发送**（可含小数点，如 `25.01`）（PDF 4.4）。
- **校验**：从命令首字符异或到 `#` 符号本身（含 `#`，不含后两位），初值 0，结果两位大写十六进制（PDF 8.3/8.4，publiccmd.c CheckSum 同算法）。使用校验必须带地址（默认机可 `@0`）。
- 示例：`TC1:TCSW=1@0#50\r`；正确执行回复 `CMD:REPLY=1@0#7D\r`。

## 2. 应答语法

- 查询成功：`MODULE:PARAM=VALUE\r`（**回显完整参数名**）。
- 设定/保存/一切错误：`CMD:REPLY=ERRORCODE\r`（**不是回显参数名**——解析器必须按此分路）。
- 带地址时应答末尾附 `@X`（PDF 7.5）；用校验时同样附 `#YY`（8.2）。
- 无地址后缀的命令 = 与"上一次通讯的下位机"继续（PDF 7.4）——单机场景无影响。

## 4. 时序铁律（PDF 4.6）

- **两条下行命令间隔 ≥50ms**，小于则可能不被受理。
- 官方建议：设定后等 50ms 再发查询验证——我方**写后读回校验按此节流**（M207 队列 50ms/条）。
- **实证**：EasyHost 出厂配置 `SendInterval=0.05`（秒）——厂商上位机即按 50ms 发送。

## 5. 保存语义（PDF 2.3）

- `!` 保存**当前设定值**供下次开机读取；只有可设定参数才可能可保存，**并非所有可设参数都可保存**。
- 每参数"可存性"在 H10 映射表标注列（P1）；不可存参数的 `!` 由模块回 ERRORCODE（1/3/2 依模块实现，实录确认）。
- Modbus 0x10 写不保存（PDF 10.3）——备选通道特性，记录备查。

## 6. `^` 改变命令（CHANGING）——**禁用**

- publiccmd.c 枚举含 `CMDTYPE_CHANGING`（`^` 触发）；协议 PDF V3.0 全文无此命令。
- **未证实语义前一律禁用**，固件/网页不生成、解析器不受理（P2 板无关纯函数单测锁定）。
- EasyHost 实录如出现 `^` 帧再启评估（预期不出现——脚本语料 165 行中 0 次）。

## 7. 参数字典自发现（PDF 10.4-10.5，最高真值通道）

- `PCRS232:COMPUSHLIST=1`（接口或为 `RS232:`/`UIRS232:`，视产品）→ 模块自报全部支持参数+寄存器地址/类型/长度。
- **sim 先验证语法，真机 I4 确认**；若支持，字典以设备自报为最高真值，覆盖本文第 8 节静态表。
- Modbus RTU（3xxx 只读/4xxx 读写，uint16/uint32/float 大端，站号=串口地址+1）为备选通道，**不启用**（架构 v2：ESP32 直连 UART 自定义协议即可）。

### 8.1 模块名（modulename.xml 摘录相关项）

| 模块 | 含义 | 我方用途 |
|---|---|---|
| TC1 | 温控1（单通道默认/多通道第1） | 贴身水箱 TEC |
| TC2 | 温控2 | 环境水箱 TEC |

### 8.2 核心字典（122 参按页分组；□=只读遥测，▪=可设，●=动作按钮）

**温度设置**：▪TC1/TC2:TCADJTEMP 调节温度（℃）；□TC1/TC2:TCACTTEMP 实际温度（℃）
**温度选项**：▪TCx:TCSETTEMP 设定温度；▪TCMINTEMP/TCMAXTEMP 最低/最高设定温度（默认 -10/120，**调节温度值域由本对参数动态定义**）；▪TCSTEPTEMP 步进（默认 0.01）；▪TCRAMPSPEED 限速（℃/秒）；▪TCDECIMALDIGITS 小数位
**输出设置及状态**：▪TCx:TCSW 开关；▪TCMODE 输出模式（0=致冷…见 tc_opt.xml）；▪TCMAXV 最大输出电压（V）；▪TCCOOLVRATIO 冷热电压比值；▪TCSETVOL 预计输出电压（V）；□TCACTVOL/TCACTCUR 实际电压/电流；□TCOE 功率输出状态
**输出状态详注（m1"模式"页，2026-11-26 补）**：□TC1/TC2:TCACTVOL 实际输出电压（V，制热为负）；□TC1/TC2:TCACTCUR 实际输出电流（A，恒为正）。来源：EasyHost 参数字典（`docs/evidence/easyhost_decompile/m207_dict_*.csv`，"输出设置及状态"组）与用户手册。真机 2026-11-26 00:14 只读查询实录（诊断档 `m207 raw`，TEC 关着）：`TC1:TCACTVOL=0.023`、`TC1:TCACTCUR=0.000`、`TC2:TCACTVOL=0.020`、`TC2:TCACTCUR=-0.000`——电流可以回负零，解析要吃掉。固件在线时每秒把这两条各问一遍（两通道共四条，只借温度轮询的空档，应答窗早于下一次温度轮询结束）；"模式"页的功率 = |电压| × 电流。模块不认这两条（回错误码或不应答）时连续 3 次后停止轮询，复联后重试。
**PID 设置**：▪TCx:TCPIDP/TCPIDTI/TCPIDTD 比例/积分/微分；▪TCPIDTYPE/TCPIDALGO 类型/公式；▪TCPIDWINDOW 开关窗（℃）；▪TCPIDACCWINDOW 加速窗；▪TCCTRLINTERVAL 控制间隔（ms）；□TCTUNESTATUS 整定进度
**过温保护**：▪TCx:TCOTPHT/TCOTPLT 高/低阈值；▪TCOTPHHYS 滞回；▪TCOTPMODE 模式；□TCOTPSTATUS 结果
**过流保护**：▪TCx:TCOCPADJTHR 阈值调节（A）；□TCOCPACTTHR 实际阈值；▪TCCURLIMIT 限流；□TCOCPSTATUS 结果
**过压保护**：▪TCx:TCOVPADJTHR（V）；□TCOVPACTTHR；□TCOVPSTATUS
**传感器开路保护**：▪TCx:TCRTOCPHT/TCRTOCPPLT；□TCRTOCPSTATUS
**错误状态及自动恢复**：▪TCx:TCERRORMASK 掩码；□TCERRORSTATUS/TCERRORLOG；▪TCAR 自动恢复次数；▪TCARDELAY 延迟；□TCARCNT
**外部状态**：▪TCx:TCEXTCTRL；□TCEXTSTATUS
**下位机自身温度（PCB）**：□TMACTTEMP；▪TMOTPHT/TMOTPLT/TMOTPHHYS 过温三件套；▪TMDTPHT/TMDTPLT/TMDTPHHYS 危温三件套；□TMOTPSTATUS/TMDTPSTATUS
**参数与存储**：▪MEMORY:MEMWP 存储内容保护；▪PARAM:BATCH 批量处理；●PARAM:BATCHDEFAULT/BATCHSAVE 批量恢复/保存
**串口**：▪PCRS232:COMADDR/COMBAUDRATE/COMMODBUS；▪UIRS232:COMADDR/COMMODBUS
**常规信息（全只读）**：□SYSTEM:SYSMODEL/SYSSN/SYSVERSION/SYSPVIN/SYSTIME/SYSCOMPANY/SYSWEBSITE
**自定义**：●SYS:RESET 重启下位机

> "可设/只读"初判依据：BTN=动作、数值遥测（ACT/STATUS/CNT/LOG）=只读、其余=可设；**逐参"可存性"与读写权限以 COMPUSHLIST 自报+实录为准**（冲突入第 10 节清单）。枚举值语义见 tc_opt.xml（OPT_TCMODE：0=致冷 1=致热 2=…等，全文在证据）。

## 真机勘误补注（2026-10-26，R1b 真机阶段实录；证据=docs/evidence/R1b_realprobe_full.log）

1. **无 `` 命令不被静默忽略**（§1 修正）：实测无帧尾 `` 的命令在帧间隙超时后被解析并回 `CMD:REPLY=2`（同一参数 `TCADJTEMP?` 带 `` 回正常值、不带回 2，唯一变量=帧尾）。本工程防线：send_raw 统一补 ``（m207_service.c API 契约）。
2. **COMPUSHLIST 应答格式**（§7 补充）：`PCRS232:COMPUSHLIST=1` → `CMD:REPLY=1` 后跟流式 `TCx:参数名.REG=寄存器号_类型` 行（类型实测 `_FLOAT`/`_UINT16_2`；TC1 块自 3001、TC2 块自 3201——MODBUS 风格寄存器号）。表内无 TCSENSORTYPE/TCADJTEMP（后者有独立应答，别名关系见 C1）。
3. **TCERRORSTATUS/LOG 为锁存寄存器**：传感器修复后 bit4 仍 0（239），需模块断电重启才清（手册 §5.7-5.9 锁存条款的寄存器体现）；断线实时性由"参数族隐藏→errcode=2"承载（F6 检测主路径）。
4. **轮询期 errcode≠通信失败**（服务层语义）：`CMD:REPLY` 应答本身=链路双向活证据；本工程按 m207_classify_poll_errcode 三态分类（断线候选 3 连去抖/unexpected 留痕），见 R1.md R1b 节。
