## 1. 设计原则（ISA-101 对齐，四条）

1. **层级显示**：主页（唯一常驻）→ 调参/连接 → 弹窗/角标，共三级。
2. **灰阶底、颜色只留给报警**：主页默认无彩色——卡 #F2F3F5 + 描边 #D8DEE6 + 深灰字；
   蓝 #2563EB 只出现在交互元素（按钮描边/选中行/滑条拖动）；红/黄只给报警；"正常=安静灰，异常=一点红"。
3. **报警分级防疲劳**：同屏只显示最高级横幅一条，其余计数角标"还有 N 条"。
4. **情境意识=5 秒三问**：任何时刻主页 5 秒内回答"安全吗（横幅+TEC 胶囊）/水温多少（两张 hero 卡）/在做什么（模式胶囊+风扇开关）"。

## 4. 交互规范

- 触摸→变色 <100ms（patch 直绘零翻转）；参数→回显 ≤1s；EEPROM 固化后 2s 出"已保存"角标 1s。
- 长按连发 400ms 首发/150ms 节奏（± 键）。
- 滑条（K4b）：像素→值线性映射 step 对齐；拖动跟手 ≤20Hz；**拖出轨道 ±32px=取消回弹**；
  松手 **1s 防抖**后生效下发；±/步进/翻页与拖动并发=后到操作优先（取消未生效拖动）；
  取消的拖动不再放行 tap。触摸校准=I5 真人一次（sim 注入不依赖校准）。
- 高温设定（>tc_set_confirm）二次确认；急停/恢复默认二次确认（弹窗双键间距 ≥48）。
  （2026-11-25 更正：急停的入口规则以文末"v1.2 增补章 §E"为准——短按仍二次确认，首页**按住 ≥600ms 直接急停**。）
- 夜间机器门禁：可点 rect 尺寸/间距/8px 网格/字号档/对比度（ui_layout.h 静态断言 +
  tools/vision_audit.py + mock_diff.py）。

## 微观工艺章（v1.1，WP-L1；随 H17 立章：宏观达标仍会因 1-2px 微瑕报废观感）

1. **全 rect 整数坐标**；同类元素间距全等（差异必须入豁免表+设计意图，如底栏急停 56px 隔离距）。
2. **文本对比度门槛**：≤24px 文本 ≥4.5:1（图元 ≥3:1）。v1.1 落地：次级文字 #5F6B7A→#44506B（card 7.26:1）、绿 #16A34A→#15803D（card 4.0:1）。机器断言=tools/geom_audit.py §4。
3. **状态点锚定（D4 类）**：一切呼吸点/链路点用 ui_layout.h `UI_DOT_*` 常量（正典 mock 聚类坐标），**禁止随文本宽度浮动**；点若在数值 patch 同步区外必须自带 patch（D4 教训：区内假象掩盖跨区丢失）。
4. **表宽数字（D3 类）**：周期重绘的数字串（时钟/状态行/计数）按固定单元渲染（每字符一格），禁止比例宽逐秒变宽；文本布局唯一出口（measure+draw 同源）。
5. **圆角件邻接规则（D2 类）**：圆角旋钮与轨道端帽同圆时，角部补切方向必须与 ui_round_rect 一致（左帽从左量/右帽从右量）；**镜像对称断言**（两态轨道轮廓逐行 diff=0）入 nightly（tools/l1_assert.py）。
6. **警示图标（D3b 类）**：▲ 警示三角必须含叹号（三角内警示色像素 ≥120 且内部底色叹号像素 ≥12，断言在案）。
7. **fb_dump 静息帧规约（T-10）**：取证帧在重绘窗口外取（console 触发后沉降 ≥1s），防慢读伪影。
8. **豁免表**：几何豁免见 tools/geom_audit.py GRID_EXEMPT/GAP_EXEMPT（每条带规范/裁决依据）；新增豁免必须同步入本章。

## v1.2 增补章（2026-11-25；独立复核 R5 的销号条件 C1——此前规则只在代码和提交说明里，规范没有同步）

### E. 急停屏入口规则

急停之后：急停键转灰、不可再按；出现红色横幅"急停已触发"。点横幅 = 向主控发确认解除，主控回话后按钮回红。
急停复位后是手动模式，不会自动重启温控（横幅点击后的提示条会写明）。
