# 调温服 现行规格说明书 v1.1（正典，H12）

> **本文档是唯一现行规格**。历史任务书（v2.3/v2.4/v5.1/v6.2/v7.x）中的规格条目凡与本文冲突，以本文为准；变更史见 §9。
> 基线：v2.4 合并基线 + 第二/三阶段勘误与变更（WP-A~H）；fw v1.1.0（2026-10-19）。

## 1. 系统架构

```
                     ┌────────────────────────────────────────────┐
   M207 温控模块 ◀──▶ │ STM32H743IIT6（地面站板=主控）               │
   USART3 57600       │  ┌──────────────────────────────────────┐  │      手机
   TMP117 体温 ◀──I2C─│  │ 驱动层: ltdc/ft5446/uart/i2c/eeprom  │  │   ┌─────────┐
   风扇 ◀─────────────│  │    ⇅ 单向依赖                         │  │   │ WiFi STA│
   ESP32-S3 ◀─UART2───│  │ 服务层: param_registry(唯一数据源)    │  │   │  ↓ HTTP │
   (PD5/PA3 飞线)     │  │          m207/tmp117/control/post    │  │◀──│  ↓ WS   │
   7" 1024×600 ◀─LTDC─│  │    ⇅ 单向依赖                         │  │   │ 手机网页 │
   FT5446 触摸 ◀──────│  │ 视图层: tcs_ui/console/link(帧收发)   │  │   └─────────┘
                      │  └──────────────────────────────────────┘  │
                      │  ESP32-S3 = 纯桥 + SoftAP + Web 服务器      │
                      └────────────────────────────────────────────┘
```

- **注册表 = 唯一数据源**：屏/网页/CLI 全部视图由注册表生成；id 永久分配永不复用不改义；消息只加不改载荷。
- **三层依赖单向**：驱动 ← 服务 ← 视图；服务层（registry/m207/tmp117/control/post）零 HAL 依赖、PC 单测直接编译；板级副作用经 hooks 注入。
- **ISR 只置标志/单字节入环**，一切发送在主循环（三处唯一 HAL_UART_Transmit 消费点）。
- **DMA2D 永久弃用**（+32px/行异常、挂死总线、小搬运高开销三重实证）。复活必测三条：①逐行 R2M 步进 ②总线竞争 ③小搬运开销。
- **乒乓双缓冲**：CFBAR 翻页零拷贝；同步（整帧 memcpy）仅允许"切页/弹窗/按住沿(H1)/boot"四类整页事件——`gfx_sync_buffers` 方向=新帧→旧帧缓冲（H1 修正，原实现反拷贝）。
- **扩展成本表**：加参数=注册表 1 行（+映射表 1 行）；加外设=三函数模板；加页面=页表项+帧函数；OTA 通路已留（ESP32 双分区+网络 OTA）。

## 2. 参数注册表 v1.1（id 权威定义）

| id | key | 名称 | 类型 | 范围/步进 | 默认 | flags |
|---|---|---|---|---|---|---|
| 0x01 | tc1_set | 贴身水箱设定温度 | f32 | 5~45 / 0.1 | 25.0 | RW·SCREEN·WEB·PERSIST·M207 |
| 0x02 | tc2_set | 环境水箱设定温度 | f32 | 5~45 / 0.1 | 25.0 | RW·SCREEN·WEB·PERSIST·M207 |
| 0x03 | body_hot | 体温过热阈值 | f32 | 36~40 / 0.1 | 37.5 | RW·SCREEN·WEB·PERSIST |
| 0x04 | body_cold | 体温过冷阈值 | f32 | 35~39 / 0.1 | 36.5 | RW·SCREEN·WEB·PERSIST |
| 0x05 | hyst | 滞回回差 | f32 | 0.1~1 / 0.1 | 0.2 | RW·SCREEN·WEB·PERSIST |
| 0x06 | mode | 控制模式 | u8 | 0~1 / 1 | 0(手动) | RW·SCREEN·WEB·PERSIST |
| 0x07 | tc_set_confirm | 高温二次确认阈值 | f32 | 38~45 / 0.5 | 40.0 | RW·WEB·PERSIST |
| 0x08 | commissioned | 布防模式 | u8 | 0~2 / 1 | 0(auto) | RW·SCREEN·WEB·PERSIST |
| 0x100 | m207_kp | M207 PID 比例（占位） | f32 | 0~10 / 0.1 | 1.0 | RW·WEB·PERSIST·M207 |
| 0x101 | m207_ki | M207 PID 积分（占位） | f32 | 0~1 / 0.01 | 0.1 | RW·WEB·PERSIST·M207 |

- **0x08 三态语义（H6 起）**：0=auto（POST 过且数据源健康→布防）；1=强制布防（FMEA 恒开）；2=强制不布防（安静，未接线/演示）。旧 0/1 值兼容。
- 约束：body_cold < body_hot（写任一侧校验另一侧，违反拒写）。
- EEPROM v2 布局：0xA6 magic / ver=2 / count / 8B 记录×N / CRC8@0xF8；自测字节 0xF6（写后必须还原）。
- 只读快照 g_tcs：tc1_act/tc2_act/body_temp/tec1/tec2/fan/mode/alarm/m207_online/body_sensor_ok/esp_link_ok/fw_ver(0x010100=v1.1.0)。

## 3. 安全控制（control.c，安全常量硬编码不进参数表）

- 制热目标 45.0°C / 制冷目标 15.0°C / 过热硬阈值 48°C（任意模式自动置 ALM_OVERTEMP，不受布防影响）。
- 自动模式迁移：IDLE→(>hot+hyst)→COOL(TC1=15+风扇开)；COOL→(<hot−hyst)→IDLE；IDLE→(<cold−hyst)→HEAT(TC1=45+风扇开)；HEAT→(>cold+hyst)→IDLE。
- **布防三态机（post.c，H6）**：UNARMED_ABSENT ⇄ ARMED_ONLINE ⇄ LOST_ALARM。ARMED→LOST=数据源失联沿（SAFE+报警）；LOST→ARMED=人工清报警 且 连续 10 次健康采样（上线补入）。
- **合理性滤波（H6.7）**：体温样本 25~45°C 且 |Δ|≤2°C/s（违者按通信错误计入健康计数）；M207 回读 |Δ|>10°C/s 判不可信→按失联路径。
- SAFE：TEC 双停 + 风扇强制开 + 报警位；退出=双源恢复 + 人工确认（ack）。
- 急停（屏弹窗/网页二次确认/KEY0/CLI 同一入口）：TCSW 双停 + 风扇全开 + mode=手动 + ALM_ESTOP，自持需 ack。
- 未布防：传感器类异常只记状态沿，不横幅不进 SAFE（安静）；过热/急停不受布防影响。

## 4. POST 上电自检（post.c，H6）

六项：①TMP117 Device ID==0x0117 ②M207 一拍内首联（宽限 2.5s）③EEPROM 镜像 CRC ④参数表自洽（序列化 CRC+范围）⑤屏+触就绪 ⑥版本/协议/注册表非空。
- 角标 (128,0,640,40) 16px，✓绿(0x16A34A)/✗黄(0x92400E)，3s 淡出；`post badge [ms]` 重显。
- 结论进布防 auto 判据；结果如实显示（触屏 IC 硬件离线→✗，不粉饰）。

## 5. 链路协议（H743↔ESP32，tcs_proto.h 双端同源）

- 帧层 AA 55|Len|Payload|CRC8；ARQ 500ms×3。消息：0x10 STATUS(19B,500ms)/0x11 PARAM 变更即推/0x12 SET_PARAM/0x13 GET_REGISTRY/0x14 REGISTRY_ENTRY/0x15 CMD/0x90 ACK。
- 报警位：0x0001 体温 / 0x0002 M207 / 0x0004 急停 / 0x0008 过热 / 0x0010 EEPROM。
- 勘误：STATUS 长度 19B（v2.3 任务书表尾"17B"系算术口径漏加 online+rfu，以字段清单为准）。
- 同步预算：网页↔屏 ≤1s = 500ms STATUS + 500ms 屏扫描（端到端实测留 I1/I5）。

## 6. 网页（ESP32 内嵌，gzip EMBED）

- 注册表驱动参数区（PF_WEB），M207 参数自动进高级区；模式/布防模式为控件特殊渲染（布防三态文案：自动/强制布防/强制不布防）。
- 重连（H2）：指数退避 1,2,4,8,10s 上限；连败 12 次（≈95s）自动整页刷新（清 JS 态；AP 整体离线为物理边界）。
- CSV 导出（H7）：`unix_time_s,body_temp_c`，30min 窗口 2s 采样。
- 触控目标 ≥44px；断连灰罩+倒计时；急停二次确认。

## 7. 触摸 UI（1024×600 浅色 17 色 + H1/H13 增补）

- 三页：P0 主页 / P1 调参 / P2 连接二维码。底栏五按钮（调参/切自动·手动/TEC1 启停/连接/急停，176px 等宽，急停 228px 实红）。
- **按住态高亮（H1）**：按下即 #E5E7EB（含 ±/步进/返回/保存/急停胶囊/风扇卡/弹窗按钮），抬起还原，连发期间保持；幽灵触点：多点忽略已有 + 相邻帧位移 >200px 丢弃（返回码 2，不合成释放沿）。
- ± 单击步进一档 + 长按 400ms 首发/150ms 连发（H3 修补：单击此前未接线）。
- 模态弹窗打开期间冻结 500ms 周期重绘（H1 修复的存量闪烁）。
- 字库：24px CJK（202 字，gen_font_cn.py 自动收集 + font_audit 永久门禁）、16px 仅 ASCII、32px 数值 2×=64px。

## 9. 版本变更史（v1.0 → v1.1 摘要）

1. 0x08 布防：0/1 → 三态（0 auto/1 强制/2 强制不布防），max=2（H6）。
2. 新增 post 服务模块（六项自检+布防三态机+合理性滤波）与角标（H6）。
3. 注册表新增 0x100/0x101 假参数占位 + M207 映射表通用通道（H10，文档到=填表）。
4. 触摸：按住态高亮 + 幽灵触点过滤 + ± 单击步进（H1/H3 修补）。
5. gfx_sync_buffers 方向修正（H1 发现的反拷贝缺陷）；模态弹窗冻结周期重绘。
6. 网页：重连指数退避+自动刷新（H2）、CSV 导出、44px 触控、步进按钮修复（H7）。
7. 主页底栏 4→5 按钮行，新增连接二维码页（H13，qrcodegen 裁剪引入）。
8. fw_ver → 0x010100（v1.1.0，H4 交付版）。
