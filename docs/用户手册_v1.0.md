# 调温服 用户手册（fw v1.1.0 · 人话版）

## 一、开机

1. 上电 → **3 秒内亮屏**。开机后顶栏会闪过一条「自检角标」（6 个小项，✓绿✗黄），3 秒自动消失——这是正常自检，不是故障。
2. 角标里 **SCR 一项打黄叉**=触摸屏 IC 没应答（硬件顽疾，M3 记录在案）：触摸可能失灵，但温控、网页不受影响。
3. **开机出现横幅怎么办**：
   - 「EEPROM 配置无效 已恢复默认」→ 参数回到了出厂值，重设一遍即可（一键恢复见下）。
   - 「体温失联 点击恢复」/「M207 失联 点击恢复」→ **曾在线后来失联=查接线**（这两条只在布防后出现）。
   - 「水温过高 >48°C」→ 立即检查水泵/水箱。
   - 点横幅=人工确认恢复。

## 二、日常操作（触摸屏）

| 想做什么 | 怎么做 |
|---|---|
| 调水温 | 底栏「调参」→ 选中参数 → 按 − / +（单击±0.1，按住连续调）→ 「保存并返回」 |
| 切自动/手动 | 底栏「切自动」（会弹确认框）、「切手动」 |
| 开关 TEC1 | 手动模式下按「TEC1 启停」 |
| 开关风扇 | 点「风扇」卡片任意位置 |
| **紧急停车** | 按「急停」→ 弹窗再按「确认」（TEC 全停、风扇全开）|
| 手机连接 | 底栏「连接」→ 出二维码；手机连上 TCS 热点后扫码自动打开网页 |

## 三、手机网页

1. 手机 WiFi 连接热点 `TCS-XXXX` → 扫屏上二维码（或浏览器输 `192.168.4.1`）。
2. 网页能看到：三个温度仪表、体温曲线、所有参数滑条、急停大按钮。
3. 屏和网页**双向同步**（≤1 秒）；断开会盖一层灰罩自动重连。
4. 「导出 CSV」下载体温历史（Excel 可开）。

## 四、布防（安全报警开关）

- 调参页「布防模式」：**自动**（推荐，自检通过即布防）/ **强制布防**（演示传感器拔线报警用）/ **强制不布防**（传感器没接时用，安静不报警）。
- 布防后拔传感器 → 顶栏黄横幅 + TEC 停 + 风扇全开（安全态）。恢复接线后**点横幅确认**才恢复。

## 五、一键恢复出厂

电脑连调试口，Git Bash 运行：`bash tools/factory_reset.sh`
（参数回默认 + 布防回自动 + 自动保存。）

## 六、常见问题

| 现象 | 处理 |
|---|---|
| 屏幕点不动 | 看角标 SCR 是否黄叉；重启试一次；仍不行→触摸排线重插（硬件） |
| 网页打不开 | 确认手机连的是 TCS 热点；浏览器输 192.168.4.1；还不行→重启设备 |
| 网页灰罩一直转 | 靠近设备；约 95 秒网页会自动刷新一次 |
| 参数断电后丢了 | 保存过吗？（调参页要按「保存并返回」） |
| 开机就响铃/横幅 | 按横幅确认；反复出现按 §一.3 查接线 |
