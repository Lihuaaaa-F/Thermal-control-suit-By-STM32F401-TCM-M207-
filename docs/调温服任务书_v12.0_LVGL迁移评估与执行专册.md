## 第一章 决策背景与现状底账

### 1.1 一句话定位

**本册回答一个问题：屏端 GUI 层从自研 tcs_ui 换成 LVGL，值不值得、怎么做、做到一半怎么退。** 回答方式不是讨论，是 G0-G6 七道门禁 + 数字化判定；G3 之前不动一行真机代码。

### 1.2 现状底账（换框架的"卖方"与"买方"）

**硬件栈（全部保留，LVGL 不碰这层）**：STM32H743IIT6（2MB Flash / 1MB 片内 RAM）；1024×600 RGB565 屏（HX8282，ID=0x7016）LTDC 直驱纯 RGB 并口（无 SPI 初始化命令）；显存外部 SDRAM @0xC0000000（FMC，Cacheable write-through）；DMA2D 现仅用于 gfx_clear/gfx_fill_rect（R2M 寄存器直写）；触摸 FT5446（软件 bit-bang I2C，时序抄 ST 官方 LVGL 例程 ft5206.c——**触摸侧本就是 LVGL 生态代码**）；裸机超级循环 10ms 节拍（v2.4 §3.2 铁律：ISR 只入缓冲置标志，参数写只在主循环；节拍预算合计 ≤8ms，余量 2ms）。

**软件栈（LVGL 的替代对象）**：`App/tcs/tcs_ui.c` 自研组件渲染（局部重绘 ≤6ms/全屏 ≤25ms，仅切页）；`ui_layout.h` 生成式组件库；token=C 设计系统（WP-K 定稿，屏端↔网页端双端同源）；字体三档位（16px ASCII font8x16.inc / 24px CJK 全量 / 32px ASCII+°℃ 数值大字，**gen_font_cn.py 从 msyh.ttc 自动收集 UI 字符集生成**，font_audit.py 永久门禁兜底缺字）。

**质量资产（迁移的真正成本所在）**：V-1 基准帧 diff=0 双时点（7 页×状态矩阵，fb_dump+diff 脚本）；mock_diff.py --suite nightly 门禁（mock↔真屏容差 diff）；渲染预算实测（hero 2.5ms/页 24.9ms）；E2E 触摸/急停/翻页相关行（E-01/04/05/12/13/15/23）；token 一致性视觉走查体系（mock/candidates+final、vision_audit.py）。

### 1.3 LVGL 是什么（给执行者的知识底座，三句话）

LVGL（Light and Versatile Graphics Library）= 开源（MIT、纯 C）嵌入式 **GUI 框架**，跑在显示驱动**之上**、业务 UI **之下**——本项目它替换的是 tcs_ui.c 那一层，**不是** ltdc.c 那一层。提供 30+ 控件（滑条/图表 chart/仪表 arc/键盘/弹层）+动画过渡+输入抽象（触摸手势/长按/惯性滚动）+脏区局部重绘+DMA2D 硬件加速后端（v9 内建）+PC 模拟器。与 ST 官方合作（X-CUBE-LVGL），H7+LTDC+DMA2D 是其标杆平台。

### 1.4 增量/非增量清单（诚实版；G3 决策的证据基准）

**真增量**：①控件库（图表/滚轮/键盘等，自研需逐个手画）②动画与页面过渡 ③手势识别（按下/长按/拖动状态机）④抗锯齿/圆角/透明混合渲染 ⑤DMA2D 从"仅填充"扩到全程（文字/控件绘制不再 CPU 裸算）⑥PC 模拟器（无硬件开发 UI，换届交接友好）⑦社区文档体量。

**不是增量（评估时禁夸大）**：①字号层级——**三档位字体体系已落地**（§1.2），LVGL 换来的只是抗锯齿渲染质量，不是"从 8×16 到多字号"②脏区局部重绘——tcs_ui 已有 ③触摸驱动——FT5446 时序本就抄 ST LVGL 例程 ④内存——现有栈占用更小，LVGL 只会多不会少 ⑤网页端——不受影响（token 双端同源体系由映射层保住，见 G1）。

**非目标**：不换屏/不动 LTDC/SDRAM/DMA2D/FT5446 驱动层；不上 RTOS（LVGL 裸机模型跑现有 10ms 主循环）；不动 ESP32 端与网页端；不做 SquareLine 等设计器引入（除非 G3 后用户另行批准）；不追求像素级等同现有渲染（G1 判定是几何/文案/颜色 token 一致 + 容差 diff，不是 diff=0）。

## 第四章 LVGL 技术底账与选型约束（G0 钉死，执行中禁漂移）

1. **版本**：v9 线最新稳定版。G0 时把「版本号 + 组件 commit + 获取方式」写入本册附录 A；此后模拟器线与真机线**同版本**，升级=重新过 G1 判定（v8→v9 破坏性迁移前科在案）。
2. **引入方式**：真机侧在 Git 子模块 /idf 或 CMake FetchContent / 源码 vendoring 三者中选一，判据=可复现构建（离线台架可编译）；G0 定案后写入附录 A。
3. **许可证**：MIT；G0 须在附录 A 记录版权头与 LICENSE 文件落位（Q7 静态分析同扫）。
4. **裸机集成模型**：lv_tick 源=HAL_GetTick（1ms，已有）；lv_timer_handler() 挂主循环每节拍调用一次，单次调用 WCET 进第六章预算表；**禁止**为 LVGL 新增中断或改 SysTick 分频。
5. **DMA2D**：v9 内建后端按官方默认开启；G4 实测开/关两组数据对照。
6. **draw buffer**：两个候选位（片内 AXI SRAM / 外部 SDRAM），G4 双方案实测帧时间定案；尺寸起点 1024×40×2B，倍率扫到 1024×120。
7. **字体管线双轨**：G1 用「tcs_font_cn.inc → lv_font 转换器」（保留现点阵观感，复刻页与现屏可比）；G2 用 lv_font_conv + msyh.ttc 直生抗锯齿字体（展示增量）。两轨共用 gen_font_cn.py 的字符集自动收集与 font_audit.py 门禁。
8. **模拟器宿主**：Windows 本机，SDL（MSYS2/MinGW）与 Visual Studio 官方移植二选一，G0 定案并出一键重建脚本；判定均以**帧文件**为证（Q-L1）。
