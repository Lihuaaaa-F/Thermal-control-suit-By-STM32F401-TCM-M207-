## 第一章 质量纲领（本册宪法；与其余各章冲突时以本章为准）

### 1.1 质量定义
高质量 ≠ 门禁全绿。门禁是地板。高质量 = 拿着放大镜的挑剔用户（用户本人标准，H17"非常小错误很影响观感"在案）在**近距离逐项看**界面后挑不出毛病。LVGL 迁移的特殊风险恰在视觉：抗锯齿边缘、混色精度、基线、字距、动画残影——全部是"整体看没事、放大看全是坑"的类别，故本册把放大检查制度化为门禁而非自觉。

### 1.2 证据等级制（每条 DoD 标注最低等级；G3 决策材料与 G6 终验项逐一核对）
- **L1 纯软件断言**（单测/静态检查）：只证代码自洽，永不单独构成验收。
- **L2 仿真/模拟器**（PC 模拟器帧/mock 注入）：本册 G0-G2 的最高可得等级，**只证"逻辑与视觉可行性"，GO 决策的充分性由 G3 用户裁决补足**；须显式标注"非最终验收依据"。
- **L3 真机逻辑取证**（真硬件 fb_dump/日志/计数器实测）：G4 起所有性能/预算/竞态结论的最低等级。
- **L4 真机物理对账**（实拍照片/慢动作视频/人眼/用户裁决）：一切"观感"结论的唯一合法等级。
- **降格规则**：硬件在场时用 L2 交差=Q12 违规（v11.3 条款直接适用）。

### 1.3 最低交付线（两道线；逐条打勾，任一不满足=不关单/不冻结）
**G3 决策线（GO/NO-GO 前置）**：①G1/G2 判定表行行挂 artifact，无空行 ②VL-16 复刻一致性总表全行三值判定（一致/有意差异/缺陷）完成 ③模拟器版 8× 放大裁片包 ≥56 片（双时点）三眼评审过 ④累计找茬 ≥15 项，坐实项全部修复+回归 ⑤G3 结果文档五节齐全（复刻质量/增量价值/成本/风险/建议）⑥用户裁决记录原文入档。
**G6 冻结线（TCS_USE_LVGL=1 转默认前）**：①VL 清单 16 项全过且实拍项双轨（fb+照片）②TL 矩阵 20 行全过并逐行标证据等级 ③v11.3 E2E 相关七行（E-01/04/05/12/13/15/23）重跑达标 ④TL-1 72h 浸泡全指标 ⑤急停 TL-9/E-04 双实测不劣化 ⑥P-4/P-5 物理对账重走 ⑦Q8 冻结构建五门同 commit 一次全过 ⑧TCS_USE_LVGL=0 产物 md5=pre-lvgl 基线实证 ⑨三眼评审 JSON 全量归档 ⑩台账回写完毕（D6）。

### 1.4 主动找茬条款（每门关单必附；**≥5 项且三类齐全**，零记录或缺类=关单驳回）
- **视觉放大类 ≥1**：任取裁片放大 8× 再看一遍（AA 边缘/混色/基线/1px 对齐）；换色觉模拟再看一遍。
- **极端输入类 ≥1**：极端值（最长串/空串/极值/负号）、换操作顺序、边界点（热区边缘±1px）。
- **竞态打断类 ≥1**：动画中触摸、连点、渲染中触发急停/翻页/报警弹出。
- 固定动作追加：用比门禁更严的标准再量一遍（容差减半重 diff）；没找到问题=没认真找。

### 1.5 放大条款（本册特设；VL-3 的册级依据）
一切"看起来没问题"的视觉结论，未附 8× 放大裁片=未检查。放大对象含两类：**渲染帧**（fb_dump/模拟器导出 PNG，nearest 上采样 8×，查渲染质量）与**实拍照片**（查面板表现：亮度/频闪/残影/视角）。裁片包命名与归档规范见 VL-3。

### 1.6 执行者开工必读（每会话第一条）
通读本册第一/二章 → v11.3 第一/二章（质量纲领与方法论母本） → 《现行UI规范_v1.1.md》（视觉权威） → v2.4 §3.2/§3.7（节拍铁律与像素规格） → 台账当阶段段+上一门找茬记录 → LVGL 官方文档对应版本 Intro/Porting/Overview（D-L1）。理解"为什么"再动手；机械执行=违规。

## 第三章 决策背景与现状底账

### 3.1 一句话定位
**本册回答：屏端 GUI 层从自研 tcs_ui 换成 LVGL，值不值得、怎么做、做到一半怎么退。** 回答方式=G0-G6 七道门禁+VL/TL 两张清单+数字化判定；G3 之前不动一行真机代码。

### 3.2 现状底账
**硬件栈（保留，LVGL 不碰）**：STM32H743IIT6（2MB Flash/1MB 片内 RAM）；1024×600 RGB565（HX8282，0x7016）LTDC 直驱纯 RGB 并口；显存外部 SDRAM @0xC0000000（write-through）；DMA2D 现仅 gfx_clear/fill_rect（R2M）；触摸 FT5446（bit-bang I2C，时序抄 ST 官方 LVGL 例程 ft5206.c——**触摸侧本就是 LVGL 生态代码**）；裸机 10ms 节拍（v2.4 §3.2 铁律：ISR 只入缓冲置标志、参数写只在主循环、节拍合计 ≤8ms 余量 2ms）。
**软件栈（LVGL 替代对象）**：tcs_ui.c（局部重绘 ≤6ms/全屏 ≤25ms）；ui_layout.h 生成式组件库；token=C 设计系统（WP-K，屏↔网页双端同源）；字体三档位 16/24/32→64px（gen_font_cn.py 自 msyh.ttc **自动收集 UI 字符集**生成，font_audit.py 永久门禁兜底缺字）。
**质量资产（迁移真正成本）**：V-1 基准帧 diff=0 双时点（7 页×状态矩阵）；mock_diff.py --suite nightly；渲染预算实测（hero 2.5ms/页 24.9ms）；E2E 触摸/急停/翻页相关行；vision_audit/colorblind_check/geom_audit/font_audit 视觉工具链。

### 3.3 增量/非增量清单（诚实版；G3 证据基准，禁夸大）
**真增量**：控件库（chart/滚轮/键盘/弧形仪表）｜动画与页过渡｜手势识别状态机｜抗锯齿/圆角/透明混合｜DMA2D 全程加速（文字/控件不再 CPU 裸算）｜PC 模拟器（无硬件开发+换届交接）｜社区文档体量。
**非增量**：字号层级（**三档位已落地**，LVGL 换来的是 AA 渲染质量而非"从 8×16 到多字号"）｜脏区局部重绘（tcs_ui 已有）｜触摸驱动（时序本抄 LVGL 例程）｜内存（只会多不会少）｜网页端（token 双出口保住即不受影响）。

## 第六章 LVGL 技术底账与选型约束（G0 钉死，执行中禁漂移）

1. **版本**：v9 线最新稳定版；G0 落附录 A（版本+commit+获取方式+文档 URL 集）；模拟器/真机**同版本同 commit**，构建脚本硬校验（TL-16），升级=重过 G1 判定（v8→v9 破坏性迁移前科）。
2. **引入方式**：Git 子模块/FetchContent/vendoring 三选一，判据=离线台架可复现构建；vendoring 优先（D-L2 读源码定责依赖它）。
3. **许可证**：MIT；附录 A 记版权头与 LICENSE 落位。
4. **裸机集成**：lv_tick 源=HAL_GetTick（1ms 已有）；lv_timer_handler 挂主循环每节拍一次，单次 WCET 进第十章预算；禁新增中断/改 SysTick 分频。
5. **颜色深度**：LV_COLOR_DEPTH=16（RGB565 直配）为基线；G0/VL-2 附 32 位渲染对比裁片组，AA 混色精度差异量化后定案；定案后禁改。
6. **DMA2D**：v9 内建后端按默认开；G4 实测开/关两组对照。
7. **draw buffer**：AXI SRAM vs SDRAM 双方案；尺寸 1024×40×2B 起点扫到 1024×120；G4 四组数字（位置×尺寸）定案。
8. **字体双轨**：G1=「tcs_font_cn.inc→lv_font 转换器」（保点阵观感，复刻可比）；G2/G5=lv_font_conv+msyh.ttc 直生 AA 字体；两轨共用 gen_font_cn.py 字符集收集+font_audit 门禁。
9. **模拟器宿主**：Windows 本机，SDL（MSYS2/MinGW）或 VS 官方移植二选一，G0 定案+一键重建脚本；一切判定以帧文件为证（Q-L1）。
10. **裁片工具链**：G0 交付 `crop8x.py`（fb PNG→按命名规范出 8× nearest 放大裁片包）+命名规范文档；VL-3 的执行依赖。
