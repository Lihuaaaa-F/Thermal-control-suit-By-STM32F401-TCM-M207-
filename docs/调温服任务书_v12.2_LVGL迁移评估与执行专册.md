## 第一章 质量纲领（本册宪法；与其余各章冲突时以本章为准）

### 1.1 质量定义（高质量"你懂吗"的正答）
高质量 ≠ 门禁全绿——门禁是地板不是天花板。本项目高质量 = **①每个结论与物理世界对过账**：性能结论有实测数字、视觉结论有放大裁片+实拍、时延结论有物理测量、观感结论有人眼/真人；**②交付物经得起最挑剔用户上手挑毛病**（H17"非常小错误很影响观感"标准）。只过软件门禁=未完成；"清单上列了但没真做"=比不做更恶劣（Q12 加重）。

### 1.2 证据等级制（每条 DoD 标注；G6 终验涉感知项全 ≥L4）
**L1** 纯软件断言（单测/静态检查）：只证代码自洽，永不单独验收。**L2** 仿真/模拟器（PC 帧/mock）：只证可行性，显式标注"非最终验收依据"；硬件在场用 L2 交差=Q12 违规。**L3** 真机逻辑取证（fb_dump/日志/计数器实测）。**L4** 真机物理对账（实拍/慢动作/人眼/真人/用户裁决）：一切"观感""手感""流畅"结论的唯一合法等级。

### 1.3 最低交付线（两道线逐条打勾；任一不满足=不关单/不冻结）
**G3 决策线**：①G1/G2 判定表行行挂 artifact ②VL-16 复刻总表 ≥40 行三值判定 ③模拟器裁片包 ≥56 片（双时点）**且三轮独立盲审全过（1.5）** ④U-1 交互路径矩阵模拟器版全路径走查 ⑤累计找茬 ≥15 项坐实全修复 ⑥G3 结果文档五节 ⑦用户裁决原文入档。
**G6 冻结线（12 条）**：①VL 16 项全过（实拍项双轨）②TL 20 行全过标等级 ③**PL 8 项物理实测全过** ④**U 12 项全过**（含 UI 代码人审清单全勾+旁观者任务盲测）⑤E2E 七行重跑 ⑥TL-1 72h 浸泡 ⑦急停双实测 ⑧Q8 五门同 commit ⑨=0 md5 基线 ⑩**三轮盲审全记录归档（VL-3/VL-16/U-1 三对象）** ⑪三眼评审 JSON 归档 ⑫台账回写（D6）。

### 1.4 主动找茬条款（每门关单必附 ≥5 项且三类齐全，零记录或缺类=驳回）
视觉放大类 ≥1（裁片 8× 再看+色觉模拟再看）｜极端输入类 ≥1（极端值/空串/边界点±1px/换操作顺序）｜竞态打断类 ≥1（动画中触摸/连点/渲染中急停或弹层）。固定动作：容差减半重 diff 一遍、用更严标准再量一遍。**找茬与 1.5 盲审是两个独立机制，不得互替。**

### 1.5 三轮独立盲审制度（视觉与逻辑审查的通过条件；D-L11）
- **对象**：VL-3 裁片包、VL-16 复刻总表、U-1 交互路径矩阵、G3 结果文档。
- **轮次 ≥3，全部独立**：R1=产出会话自查；R2=**隔 ≥4h 或新会话**重审；R3=**隔日或换执行者**。每轮开工只给"裁片包+判定标准"，**禁看前轮判定表**；裁片呈现顺序每轮随机重排（盲号制，文件名映射表单独归档）；违反独立性=该轮作废重走。
- **记录**：每轮独立判定表（时间戳/盲号/逐片结论/发现），三轮分表归档 `docs/evidence/LVGL/blind_review/对象_R1|R2|R3.md`，轮序时间戳可对账（Q-L9）。
- **汇总与通过**：三轮发现取**并集**=问题全集；坐实项修复后**重出包、全部三轮重走**（防修复引入新问题），直至出现"三轮零缺陷零分歧"的一轮组合才通过。**"确定没问题了才能通过"=以最后一轮全零盲审为准，不以任何人前一轮的"我看过了"为准。**
- 视觉模型三眼评审作为额外一轮叠加，不替代自查轮。

### 1.6 放大条款
一切视觉结论必附 8× 放大裁片（渲染帧 nearest 上采样查渲染质量；实拍照片查面板表现；两轨互不可替代，D-L10）。裸眼看"没问题"=未检查。

### 1.7 执行者开工必读（每会话第一条）
本册第一/二章 → v11.3 第一/二章（母本） → 《现行UI规范_v1.1.md》 → v2.4 §3.2/§3.7 → 台账当阶段段+上一门找茬与盲审记录 → LVGL 官方文档钉定版本 Intro/Porting/Overview/Performance（附录 A URL 集）。理解"为什么"再动手；机械执行=违规。

## 第二章 调试方法论（**遇到问题：先看文档，再勇敢尝试；调试就是不断尝试，不断尝试才会解决问题**）

- **D1 先看文档**（任何"不知道为什么"的时刻，动手前必做，按序）：①本册+UI 规范（涉协议再+M207 正典）②**LVGL 官方文档钉定版本页 + FAQ + GitHub issue 搜索**（别人踩过的坑优先排掉——UI 渲染类问题 80% 有现成答案）③台账 grep 关键词（全部历史教训）④docs/results+evidence（同类问题可能已解）⑤源码实测注记。查完仍不明=进入 D2。
- **D2 假设→一次一变量**：拆假设清单，每次实验只改一个变量；实验前写预期，实验后对照。"试"是科学试，不是乱试。
- **D3 勇敢尝试**：调试就是不断尝试——不明确就设计实验（换参数/换缓冲方案/注帧/断开重连/代码实验分支），大胆做、做完记录；实验代码大胆改，结论入日志后按门禁决定回收——**实验代码不怕写错，就怕不回收**。禁止两种状态：①猜了一下不敢动卡住 ②同一尝试原样重复第三次。
- **D3b 停止边界**：常规问题按 D1-D3 自主迭代**不停**；仅 ①可能损坏硬件 ②需采购器材 ③需用户感官/裁决——才停并报告（附试验日志）。
- **D4 勇敢≠鲁莽**：带电插拔、任何 5V 接入、电源短路、未核对引脚上电=绝对禁止（本册 G4+ 才涉硬件）。
- **D5 试验日志**：`docs/evidence/debug/G*n_日期.md`：时间/现象/假设/步骤（含预期）/结果/结论/下一步。**试错不算失败；没记录的试错才算失败。**
- **D6 知识闭环**：结论回写台账一行（必要时进正典/勘误），防下个执行者重踩；Q3 反抽查含台账回写核查。
- **D-L1 库文档先于猜测**：LVGL 行为疑义第一动作查官方文档**钉定版本**页，第二动作读 vendoring 源码——禁猜 API 语义。
- **D-L2 库内问题最小复现定责**：疑库缺陷先在官方模拟器剥离最小复现，出"我方 port/库/后端"三边定责表，未定责不修。

## 第三章 决策背景与现状底账

### 3.1 一句话定位
**本册回答：屏端 GUI 层从自研 tcs_ui 换成 LVGL，值不值得、怎么做、做到一半怎么退。** 回答方式=G0-G6 七门+VL/TL/PL/U 四张清单+三轮盲审+数字化判定；G3 前不动一行真机代码。

### 3.2 现状底账
**硬件栈（保留）**：STM32H743IIT6（2MB Flash/1MB RAM）；1024×600 RGB565（HX8282，0x7016）LTDC 直驱；显存 SDRAM @0xC0000000（write-through）；DMA2D 现仅 clear/fill_rect；FT5446 触摸（bit-bang I2C，时序抄 ST 官方 LVGL 例程——触摸侧本就是 LVGL 生态代码）；裸机 10ms 节拍（v2.4 §3.2：ISR 只入缓冲置标志、参数写只在主循环、节拍合计 ≤8ms 余量 2ms）。
**软件栈（替代对象）**：tcs_ui.c（局部 ≤6ms/全屏 ≤25ms）；ui_layout.h 生成式组件库；token=C（WP-K，屏↔网页同源）；字体三档位 16/24/32→64px（gen_font_cn.py 自动收集字符集，font_audit 门禁）。
**质量资产**：V-1 基准帧 diff=0 双时点；mock_diff nightly；渲染预算（hero 2.5ms/页 24.9ms）；E2E 相关行；vision/colorblind/geom/font_audit 工具链。

### 3.3 增量/非增量清单（诚实版；G3 证据基准）
**真增量**：控件库（chart/滚轮/键盘/弧形仪表）｜动画与页过渡｜手势状态机｜抗锯齿/圆角/透明混合｜DMA2D 全程加速｜PC 模拟器（无硬件开发+换届交接）｜社区文档与 issue 库。
**非增量**：字号层级（三档位已落地，LVGL 换来的是 AA 质量而非层级）｜脏区重绘（已有）｜触摸驱动（本抄 LVGL 例程）｜内存（只会多）｜网页端（token 双出口保住即无影响）。

## 第六章 LVGL 技术底账与选型约束（G0 钉死禁漂移）

1. **版本**：v9 最新稳定；附录 A 记版本+commit+获取方式+**文档/FAQ/issue URL 集**；模拟器/真机同 commit，构建硬校验（TL-16）；升级=重过 G1。
2. **引入方式**：子模块/FetchContent/vendoring 三选一（判据=离线可复现；vendoring 优先——D-L2 依赖）。
3. **许可证**：MIT；版权头+LICENSE 落位入附录 A。
4. **裸机集成**：lv_tick=HAL_GetTick；lv_timer_handler 挂主循环每节拍一次；禁新增中断/改 SysTick 分频。
5. **颜色深度**：LV_COLOR_DEPTH=16 基线；G0 出 16 vs 32 对比裁片（VL-2），AA 混色精度量化后定案，定案后禁改。
6. **DMA2D**：v9 内建后端默认开；G4 开/关对照。
7. **draw buffer**：AXI SRAM vs SDRAM × 1024×40→1024×120，G4 四组数字定案。
8. **字体双轨**：G1=inc→lv_font 转换器（保点阵观感）；G2/G5=lv_font_conv+msyh.ttc（AA 轨）；共用字符集收集+缺字门禁。
9. **模拟器宿主**：Windows，SDL(MSYS2) 或 VS 官方移植，G0 定案+一键重建脚本。
10. **裁片工具链**：G0 交付 crop8x.py（fb PNG→8× nearest 裁片包+盲号随机序重排，**盲审直接可用**）+命名规范。
