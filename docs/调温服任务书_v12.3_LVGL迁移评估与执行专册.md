## 第一章 质量纲领（册宪；与其余各章冲突时以本章为准）

### 1.1 质量定义
高质量 ≠ 门禁全绿——门禁是地板。本项目高质量 = **①每个结论与物理世界对过账**（性能=实测数字、视觉=放大裁片+实拍、时延=物理测量、观感=人眼/真人）**②交付物经得起最挑剔用户上手挑毛病**（H17 标准）。只过软件门禁=未完成；"清单列了但没真做"比不做更恶劣（Q12 加重）；**自审打勾必须附核对对象，打勾≠查过（v12.2 的 C2 曾对实为孤儿的 VL-5 打过勾，教训入册）**。

### 1.2 证据等级制（每条 DoD 标注；G6 终验涉感知项全 ≥L4）
**L1** 纯软件断言：只证自洽，永不单独验收。**L2** 仿真/模拟器：只证可行性，标注"非最终验收依据"；硬件在场用 L2 交差=Q12 违规。**L3** 真机逻辑取证（fb_dump/日志/计数器实测）。**L4** 真机物理对账（实拍/慢动作/人眼/真人/用户裁决）：一切"观感/手感/流畅"结论的唯一合法等级。

### 1.3 最低交付线（逐条打勾且**每勾附证据路径**；任一不满足=不关单/不冻结）
**G3 决策线（7 条）**：①G1/G2 判定表行行挂 artifact ②VL-16 总表 ≥40 行三值判定+三轮盲审 ③模拟器裁片包 ≥56 片双时点+三轮盲审全过 ④U-1 路径矩阵模拟器版零死路 ⑤累计找茬 ≥15 项坐实全修复 ⑥G3 结果文档**六节**（复刻质量/增量价值/UX 使用逻辑预演/成本/风险/建议）⑦用户裁决原文入档。
**G6 冻结线（13 条）**：①VL 16 项全过（实拍项双轨）②TL **21** 行全过标等级 ③PL 8 项物理实测全过 ④U 12 项全过 ⑤E2E 七行重跑 ⑥TL-1 72h 浸泡 ⑦急停双实测+**兜底注入实测（TL-9b）** ⑧Q8 五门同 commit ⑨=0 md5 基线 ⑩三轮盲审全记录归档（VL-3/VL-16/U-1）⑪三眼评审 JSON 归档 ⑫台账回写 ⑬**自审清单每勾附核对对象**。

### 1.4 主动找茬条款（每门关单必附 ≥5 项且三类齐全；零记录或缺类=驳回）
视觉放大类 ≥1（8× 再看+色觉模拟再看）｜极端输入类 ≥1（极端值/空串/边界 ±1px/换序）｜竞态打断类 ≥1（动画中触摸/连点/渲染中急停弹层）。固定动作：容差减半重 diff、更严标准再量。**找茬与 1.5 盲审独立，不得互替。**

### 1.5 三轮独立盲审制度（D-L11）
- **对象**：VL-3 裁片包、VL-16 复刻总表、U-1 交互路径矩阵、G3 结果文档。
- **轮次 ≥3 全独立**：R1=产出会话自查；R2=隔 ≥4h 或新会话；R3=隔日或换执行者。每轮只给"对象+判定标准"，**禁看前轮判定表**；呈现顺序每轮随机重排（盲号制，映射表单独归档）；违反独立性=该轮作废重走。
- **记录**：每轮独立判定表（时间戳/盲号/逐项结论/发现），分表归档 `docs/evidence/LVGL/blind_review/对象_R1|R2|R3.md`，Q-L9 核验。
- **通过**：三轮发现取并集=问题全集；坐实修复后**重出包全部三轮重走**；出现"三轮零缺陷零分歧"组合才通过——以末轮全零为准，不以任何人前轮"看过了"为准。
- 视觉模型三眼评审为额外叠加轮，不替代自查轮。

### 1.6 放大条款
一切视觉结论必附 8× 放大裁片（渲染帧 nearest 查渲染质量；实拍照片查面板表现；双轨互不可替代，D-L10）。裸眼看"没问题"=未检查。

### 1.7 执行者开工必读（每会话第一条）
本册第一/二章 → v11.3 第一/二章 → 《现行UI规范_v1.1.md》 → v2.4 §3.2/§3.7 → 台账当阶段段+上一门找茬与盲审记录 → LVGL 官方文档钉定版本 Intro/Porting/Overview/Performance（附录 A URL 集）。理解"为什么"再动手；机械执行=违规。

## 第二章 调试方法论（**遇到问题：先看文档，再勇敢尝试；调试就是不断尝试才会解决问题**）

- **D1 先看文档**（任何"不知道为什么"时刻，动手前按序）：①本册+UI 规范（涉协议再+M207 正典）②**LVGL 官方文档钉定版本页+FAQ+GitHub issue 搜索**（渲染类问题八成有现成答案）③台账 grep ④docs/results+evidence ⑤源码实测注记。仍不明→D2。
- **D2 假设→一次一变量**：拆假设清单，每次只改一个变量；实验前写预期，实验后对照。
- **D3 勇敢尝试**：不明确就设计实验（换参数/换缓冲/注帧/断开重连/代码实验分支），大胆做、做完记录；实验代码大胆改，结论入日志后按门禁决定回收——**不怕写错，就怕不回收**。禁止：①猜了不敢动卡住 ②同一尝试原样第三次。
- **D3b 停止边界**：常规问题自主迭代不停；仅 ①可能损坏硬件 ②需采购 ③需用户感官/裁决——才停并报告（附试验日志）。
- **D4 勇敢≠鲁莽**：带电插拔/任何 5V/电源短路/未核对引脚上电=绝对禁止（本册 G4+ 才涉硬件）。
- **D5 试验日志**：`docs/evidence/debug/G*n_日期.md`：时间/现象/假设/步骤（含预期）/结果/结论/下一步。**试错不算失败；没记录的试错才算失败。**
- **D6 知识闭环**：结论回写台账一行（必要时进正典/勘误）。
- **D-L1 库文档先于猜测**：疑义先查官方文档钉定版本页，再读 vendoring 源码，禁猜 API 语义。
- **D-L2 库内问题最小复现定责**：疑库缺陷先在官方模拟器剥离最小复现，出"我方 port/库/后端"三边定责表，未定责不修。

## 第三章 决策背景与现状底账

### 3.1 一句话定位
**本册回答：屏端 GUI 层从自研 tcs_ui 换成 LVGL，值不值得、怎么做、做到一半怎么退。** 回答方式=G0-G6 七门+VL/TL/PL/U 四清单+三轮盲审+数字化判定；G3 前不动一行真机代码。

### 3.2 现状底账（含硬件事实核对注记）
**硬件栈（保留）**：STM32H743IIT6（2MB Flash/1MB RAM）；1024×600 RGB565（HX8282，0x7016）LTDC 直驱；显存 SDRAM @0xC0000000；DMA2D 现仅 clear/fill_rect；FT5446 触摸（bit-bang I2C，时序抄 ST 官方 LVGL 例程）；**背光=PB5 推挽输出（开/关两态，无 PWM 调光档——ltdc.c 事实，视觉检查设计据此）**；裸机 10ms 节拍（v2.4 §3.2：ISR 只入缓冲、参数写只在主循环、节拍合计 ≤8ms）。
**软件栈（替代对象）**：tcs_ui.c（局部 ≤6ms/全屏 ≤25ms）；ui_layout.h 生成式组件库；token=C（屏↔网页同源）；字体三档位（gen_font_cn.py 自动收集字符集+font_audit 门禁）。
**质量资产**：V-1 基准帧 diff=0 双时点；mock_diff nightly；渲染预算（hero 2.5ms/页 24.9ms）；E2E 相关行；vision/colorblind/geom/font_audit 工具链。

### 3.3 增量/非增量清单（诚实版）
**真增量**：控件库｜动画页过渡｜手势状态机｜抗锯齿/圆角/混合｜DMA2D 全程加速（**附带收益：渲染期 CPU 占用下降→主循环余量/功耗改善，G5 出实测对照**）｜PC 模拟器｜社区文档与 issue 库。
**非增量**：字号层级（三档位已落地）｜脏区重绘｜触摸驱动｜内存｜网页端。

## 第六章 LVGL 技术底账与选型约束（G0 钉死禁漂移）

1. **版本**：v9 最新稳定；附录 A 记版本+commit+获取+**文档/FAQ/issue URL 集**；模拟器/真机同 commit；构建硬校验（TL-16）；升级=重过 G1。
2. **引入方式**：子模块/FetchContent/vendoring 三选一（离线可复现；vendoring 优先）。
3. **许可证**：MIT；版权头+LICENSE 落位入附录 A。
4. **裸机集成**：lv_tick=HAL_GetTick；lv_timer_handler 挂主循环每节拍；禁新增中断/改 SysTick 分频。**急停兜底检查（D-L7②）在主循环触摸轮询位实现，与 LVGL 无调用关系。**
5. **颜色深度**：LV_COLOR_DEPTH=16 基线；G0 出 16 vs 32 对比裁片（VL-2）定案后禁改。
6. **DMA2D**：v9 内建后端默认开；G4 开/关对照+**渲染期 CPU 占用对照**。
7. **draw buffer**：AXI SRAM vs SDRAM × 1024×40→1024×120，G4 四组定案。
8. **字体双轨**：G1=inc→lv_font 转换器（点阵轨）；G2/G5=lv_font_conv+msyh.ttc（AA 轨）；共用字符集收集+缺字门禁。
9. **模拟器宿主**：Windows，SDL(MSYS2) 或 VS 官方移植，G0 定案+一键重建脚本。
10. **裁片工具链**：G0 交付 crop8x.py（8× nearest 裁片包+盲号随机重排）+命名规范文档。

## 第十一章 U 清单——UX 使用逻辑与 UI 代码审查 12 项（D-L12；G1 预版/G5 全量/G6 终审）

**U-1** 交互路径矩阵：7（或 8）页×全入口（触摸/按键/console/链路事件）×出口走查表，含"急停任意页任意时刻"路径；零死路；**三轮独立盲审**。

**U-6** 错误人话化：ERRORCODE 0..8 全表呈现文案非技术人员可懂（V-5 联动），禁裸代码上屏。
**U-7** 中断恢复：调参中途注入报警/断链/急停各 ≥1 次，状态与恢复路径合理（不丢已编辑值或明确提示），逐场景记录表。

**U-9** 防呆：调参方向语义一致、极值有界面反馈（滑条到头视觉态）、单位与参数名同屏。
**U-10** UI 代码人审清单（G4 port 层首过/G5 全量）：①事件回调禁长操作/禁阻塞（主循环铁律）②对象 create/delete 配对与生命周期（联 TL-2）③状态机状态×事件穷举注释齐 ④魔法数字禁入（一律 token）⑤LVGL 反模式五条（对照官方 Performance 文档）：全屏 invalidate 滥用/深层样式拷贝/忽略对象 cache/主线程做布局重活/**indev read_cb 未按协议返回 data->state 与继续标志**。判定=逐条勾+问题修复回归。
**U-11** 状态转换穷举表：UI 状态机矩阵文档+测试对照；无未定义转移、死状态为零。
