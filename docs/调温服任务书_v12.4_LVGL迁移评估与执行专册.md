## 第一章 质量纲领（本册宪法；与其余各章冲突时以本章为准）

### 1.1 质量定义（高质量"你懂吗"的正答）
高质量 ≠ 门禁全绿。门禁是地板不是天花板。本项目高质量 = **①每个结论与物理世界对过账**：性能结论有实测数字、视觉结论有放大裁片+实拍、时延结论有物理测量、观感结论有人眼/真人；**②交付物经得起最挑剔用户上手挑毛病**（用户本人标准，H17"非常小错误很影响观感"在案）。只过软件门禁=未完成；"清单上列了但没真做"=比不做更恶劣（Q12 加重）。LVGL 迁移的特殊风险恰在视觉：抗锯齿边缘、混色精度、基线、字距、动画残影——全部是"整体看没事、放大看全是坑"的类别，故本册把放大检查制度化为门禁而非自觉。**自审打勾必须附核对对象，打勾≠查过（v12.2 的 C2 曾对实为孤儿的 VL-5 打过勾，教训入册）。**

### 1.2 证据等级制（L1-L4；每个 DoD 项标注最低等级；G3 决策材料与 G6 终验项逐一核对；G6 终验涉感知项全 ≥L4）
- **L1 纯软件断言**（单测/静态检查）：只证代码自洽，**永不单独构成验收**。
- **L2 仿真/模拟器**（PC 模拟器帧/mock 注入）：只证"逻辑与视觉可行性"，显式标注"非最终验收依据"；**硬件在场时用 L2 交差=Q12 违规**（v11.3 条款直接适用）。
- **L3 真机逻辑取证**（真硬件 fb_dump/日志/计数器实测）：G4 起所有性能/预算/竞态结论的最低等级。
- **L4 真机物理对账**（实拍照片/慢动作视频/人眼/真人/用户裁决）：一切"观感""手感""流畅"结论的唯一合法等级。

### 1.3 最低交付线（两道线；逐条打勾且**每勾附证据路径**，任一不满足=整体不关单/不冻结）
**G3 决策线（GO/NO-GO 前置，7 条）**：①G1/G2 判定表行行挂 artifact，无空行 ②VL-16 复刻一致性总表 ≥40 行全行三值判定（一致/有意差异/缺陷）完成+三轮独立盲审 ③模拟器版 8× 放大裁片包 ≥56 片（双时点）**三轮独立盲审全过（1.5）** ④U-1 交互路径矩阵模拟器版全路径走查零死路 ⑤累计找茬 ≥15 项，坐实项全部修复+回归 ⑥G3 结果文档**六节**齐全（复刻质量/增量价值/UX 使用逻辑预演/成本/风险/建议）⑦用户裁决记录原文入档。
**G6 冻结线（TCS_USE_LVGL=1 转默认前，13 条）**：①VL 清单 16 项全过且实拍项双轨（fb+照片）②TL 矩阵 **21** 行全过并逐行标证据等级 ③**PL 物理实测 8 项全过** ④**U 清单 12 项全过**（含 UI 代码人审清单全勾+旁观者任务盲测）⑤v11.3 E2E 相关七行（E-01/04/05/12/13/15/23）重跑达标 ⑥TL-1 72h 浸泡全指标 ⑦急停双实测+**兜底注入实测（TL-9b）** ⑧Q8 冻结构建五门同 commit 一次全过 ⑨TCS_USE_LVGL=0 产物 md5=pre-lvgl 基线实证 ⑩**三轮盲审全记录归档（VL-3/VL-16/U-1 三对象）** ⑪三眼评审 JSON 全量归档 ⑫台账回写完毕（D6）⑬**自审清单每勾附核对对象**。

### 1.4 主动找茬条款（防打勾式执行的核心机制；每门关单必附；**≥5 项且三类齐全**，零记录或缺类=关单驳回）
- **视觉放大类 ≥1**：任取裁片放大 8× 再看一遍（AA 边缘/混色/基线/1px 对齐）；换色觉模拟再看一遍。
- **极端输入类 ≥1**：极端值（最长串/空串/极值/负号）、换操作顺序、边界点（热区边缘±1px）。
- **竞态打断类 ≥1**：动画中触摸、连点、渲染中触发急停/翻页/报警弹出。
- 固定动作追加：用比门禁更严的标准再量一遍（容差减半重 diff）；照片放大 8× 再看一遍。没找到问题=没认真找。
- **找茬与 1.5 盲审是两个独立机制，不得互替。**

### 1.5 三轮独立盲审制度（视觉与逻辑审查的通过条件；D-L11）
- **对象**：VL-3 裁片包、VL-16 复刻总表、U-1 交互路径矩阵、G3 结果文档。
- **轮次 ≥3，全部独立**：R1=产出会话自查；R2=**隔 ≥4h 或新会话**重审；R3=**隔日或换执行者**。每轮开工只给"对象+判定标准"，**禁看前轮判定表**；裁片呈现顺序每轮随机重排（盲号制，文件名映射表单独归档）；违反独立性=该轮作废重走。
- **记录**：每轮独立判定表（时间戳/盲号/逐片结论/发现），三轮分表归档 `docs/evidence/LVGL/blind_review/对象_R1|R2|R3.md`，轮序时间戳可对账（Q-L9）。
- **汇总与通过**：三轮发现取**并集**=问题全集；坐实项修复后**重出包、全部三轮重走**（防修复引入新问题），直至出现"三轮零缺陷零分歧"的一轮组合才通过。**"确定没问题了才能通过"=以最后一轮全零盲审为准，不以任何人前一轮的"我看过了"为准。**
- 视觉模型三眼评审（自视裁片+视觉模型+用户抽 ≥20%）作为额外一轮叠加，不替代自查轮。

### 1.6 放大条款（本册特设；VL-3 的册级依据）
一切"看起来没问题"的视觉结论，未附 8× 放大裁片=未检查。放大对象含两类：**渲染帧**（fb_dump/模拟器导出 PNG，nearest 上采样 8×，查渲染质量）与**实拍照片**（查面板表现：亮度/频闪/残影/视角）。裁片包命名与归档规范见 VL-3。

### 1.7 执行者开工必读（每会话第一条）
通读：本册第一/二章 → v11.3 第一/二章（质量纲领与方法论母本） → 《现行UI规范_v1.1.md》（视觉权威） → v2.4 §3.2/§3.7（节拍铁律与像素规格） → 台账当阶段段+上一门找茬记录与盲审记录 → LVGL 官方文档对应版本 Intro/Porting/Overview/Performance（附录 A URL 集）。理解"为什么"再动手；机械执行=违规。

## 第二章 调试方法论（**遇到问题：先看文档，再勇敢尝试；调试就是不断尝试，不断尝试才会解决问题**；v11.3 D1-D6 全量适用并内联如下，本册追加两条）

- **D1 先看文档**（任何"不知道为什么"的时刻，动手前必做，按序）：①本册+《现行UI规范_v1.1.md》（涉协议再+《现行M207协议_v1.md》正典）②**LVGL 官方文档钉定版本页 + FAQ + GitHub issue 搜索**（别人踩过的坑优先排掉——UI 渲染类问题 80% 有现成答案）③`docs/台账.md` 全部历史决策教训（**先 grep 关键词**）④docs/results+evidence（同类问题可能已解）⑤源码实测注记（带日期注释）。查完仍不明=进入 D2。
- **D2 假设→一次一变量**：未知现象拆假设清单，每次实验只改一个变量；实验前写预期，实验后对照。"试"是科学试，不是乱试。
- **D3 勇敢尝试条款**：调试就是不断尝试——不明确就设计实验（换参数/换缓冲方案/注帧/断开重连/代码实验分支），大胆做、做完记录。代码实验工作法：大胆改出实验分支验证假设，结论入日志后按门禁决定 revert 或保留——**实验代码不怕写错，就怕不回收**。禁止两种状态：①猜了一下不敢动卡住 ②同一尝试原样重复第三次。
- **D3b 停止边界收窄**：常规问题按 D1-D3 自主迭代**不停**；只有 ①可能损坏硬件 ②需采购器材 ③需用户感官裁决——才停并报告，报告必附试验日志。
- **D4 勇敢≠鲁莽**：带电插拔、任何 5V 接入、电源短路、未核对引脚上电——绝对禁止（本册 G4+ 才涉硬件）。
- **D5 试验日志**（新证据类型）：`docs/evidence/debug/G*n_日期.md`：时间/现象/假设/实验步骤（含预期）/结果/结论/下一步。**试错不算失败；没记录的试错才算失败。**
- **D6 知识闭环**：每个调试结论回写台账一行（必要时进正典/勘误）——防下一个执行者重踩；Q3 反抽查含"台账是否回写"。
- **D-L1 库文档先于猜测**：LVGL 行为疑义第一动作查官方文档**钉定版本**页，第二动作读 vendoring 源码——库源码在手，禁"猜 API 语义"。
- **D-L2 库内问题复现最小化**：疑 LVGL 库缺陷时，剥离出最小复现（官方模拟器跑）再定责"我方 port vs 库 vs DMA2D 后端"；三边定责表入试验日志，未定责不修。

## 第三章 决策背景与现状底账

### 3.1 一句话定位
**本册回答一个问题：屏端 GUI 层从自研 tcs_ui 换成 LVGL，值不值得、怎么做、做到一半怎么退。** 回答方式不是讨论，是 G0-G6 七道门禁+VL/TL/PL/U 四张清单+三轮独立盲审+数字化判定；G3 之前不动一行真机代码。

### 3.2 现状底账（换框架的"卖方"与"买方"；含硬件事实核对注记）
**硬件栈（全部保留，LVGL 不碰这层）**：STM32H743IIT6（2MB Flash / 1MB 片内 RAM）；1024×600 RGB565 屏（HX8282，ID=0x7016）LTDC 直驱纯 RGB 并口（无 SPI 初始化命令）；显存外部 SDRAM @0xC0000000（FMC，Cacheable write-through）；DMA2D 现仅用于 gfx_clear/gfx_fill_rect（R2M 寄存器直写）；触摸 FT5446（软件 bit-bang I2C，时序抄 ST 官方 LVGL 例程 ft5206.c——**触摸侧本就是 LVGL 生态代码**）；**背光=PB5 推挽输出（开/关两态，无 PWM 调光档——ltdc.c 事实，视觉检查设计据此，禁设计"亮度多档"判定）**；裸机超级循环 10ms 节拍（v2.4 §3.2 铁律：ISR 只入环形缓冲置标志、参数写只在主循环；节拍预算合计 ≤8ms，余量 2ms）。
**软件栈（LVGL 的替代对象）**：`App/tcs/tcs_ui.c` 自研组件渲染（局部重绘 ≤6ms/全屏 ≤25ms，仅切页）；`ui_layout.h` 生成式组件库；token=C 设计系统（WP-K 定稿，屏端↔网页端双端同源）；字体三档位 16/24/32→64px（gen_font_cn.py 从 msyh.ttc **自动收集 UI 字符集**生成，font_audit.py 永久门禁兜底缺字）。
**质量资产（迁移的真正成本所在）**：V-1 基准帧 diff=0 双时点（7 页×状态矩阵，fb_dump+diff 脚本）；mock_diff.py --suite nightly 门禁；渲染预算实测（hero 2.5ms/页 24.9ms）；E2E 触摸/急停/翻页相关行；vision_audit/colorblind_check/geom_audit/font_audit 视觉工具链。

### 3.3 增量/非增量清单（诚实版；G3 决策的证据基准，禁夸大）
**真增量**：①控件库（chart/滚轮/键盘/弧形仪表等，自研需逐个手画）②动画与页面过渡 ③手势识别（按下/长按/拖动状态机）④抗锯齿/圆角/透明混合渲染 ⑤DMA2D 从"仅填充"扩到全程（文字/控件绘制不再 CPU 裸算；**附带收益：渲染期 CPU 占用下降→主循环余量/功耗改善，G5 出实测对照表量化**）⑥PC 模拟器（无硬件开发 UI，换届交接友好）⑦社区文档体量。
**非增量（评估时禁夸大）**：①字号层级——**三档位字体体系已落地**，LVGL 换来的只是 AA 渲染质量 ②脏区局部重绘——tcs_ui 已有 ③触摸驱动——时序本就抄 LVGL 例程 ④内存——只会多不会少 ⑤网页端——token 双出口保住即无影响。

## 第六章 LVGL 技术底账与选型约束（G0 钉死，执行中禁漂移）

1. **版本**：v9 线最新稳定版。G0 时把「版本号 + 组件 commit + 获取方式 + **文档/FAQ/issue URL 集**」写入附录 A；此后模拟器线与真机线**同版本同 commit**，构建脚本硬校验（TL-16），升级=重新过 G1 判定（v8→v9 破坏性迁移前科在案）。
2. **引入方式**：Git 子模块/FetchContent/vendoring 三选一，判据=离线台架可复现构建；vendoring 优先（D-L2 读源码定责依赖它）。
3. **许可证**：MIT；G0 须在附录 A 记录版权头与 LICENSE 文件落位（Q7 静态分析同扫）。
4. **裸机集成模型**：lv_tick 源=HAL_GetTick（1ms，已有）；lv_timer_handler() 挂主循环每节拍调用一次，单次调用 WCET 进第十二章预算表；**禁止**为 LVGL 新增中断或改 SysTick 分频。**急停兜底检查（D-L7②）在主循环触摸轮询位实现，与 LVGL 无调用关系。**
5. **颜色深度**：LV_COLOR_DEPTH=16（RGB565 直配）为基线；G0/VL-2 附 32 位渲染对比裁片组，AA 混色精度差异量化后定案；定案后禁改。
6. **DMA2D**：v9 内建后端按官方默认开启；G4 实测开/关两组数据对照+**渲染期 CPU 占用对照**（G5）。
7. **draw buffer**：两个候选位（片内 AXI SRAM / 外部 SDRAM），G4 双方案实测帧时间定案；尺寸起点 1024×40×2B，倍率扫到 1024×120。
8. **字体管线双轨**：G1 用「tcs_font_cn.inc → lv_font 转换器」（保留现点阵观感，复刻页与现屏可比）；G2/G5 用 lv_font_conv + msyh.ttc 直生抗锯齿字体（展示增量）。两轨共用 gen_font_cn.py 的字符集自动收集与 font_audit.py 门禁。
9. **模拟器宿主**：Windows 本机，SDL（MSYS2/MinGW）与 Visual Studio 官方移植二选一，G0 定案并出一键重建脚本；判定均以**帧文件**为证（Q-L1）。
10. **裁片工具链**：G0 交付 `crop8x.py`（fb PNG→按命名规范出 8× nearest 放大裁片包+**盲号随机序重排，盲审直接可用**）+命名规范文档；VL-3 的执行依赖。
