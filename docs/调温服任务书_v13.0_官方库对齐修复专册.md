## §1 官方优先总原则（决策树；一切驱动/协议/工具新增代码强制走此树）

红线（清单 §六固化）：**禁止新增 bit-bang I2C / 手搓 RMT 时序 / 自研 JSON / 自研环形队列类**。

### W1 ft5446 软件 I2C → ST HAL I2C4（最大项；前置=R2-H743 完成+触摸基线绿；窗口=R2 后、G 线触摸移植前）
**官方依据（自研部分参考官方示例的铁律在此落实）**：
- 传输层：**ST HAL I2C**（stm32h7xx_hal_i2c.c，HAL_I2C_Mem_Read/Mem_Write 寄存器模式）+ **STM32CubeH7 官方例程**（Examples/I2C 从设备寄存器读写用法对照——正是本用例形态）；
- 时序对照：**espressif/esp_lcd_touch_ft5x06 v1.1.1 官方组件源码**（FT5446 同族；其 I2C 时钟档位/寄存器序列为对照参考，不引入——清单 F5 既定）；
- 器件上界：FT5446 数据手册 I2C 时钟规格核对（400k 档合法性）。
**实施步骤**：
1. 只替换传输层：ct_iic_* 全删，`ft5446_rd_reg/wr_reg` 内部改 HAL I2C4（地址 0x38<<1）；**函数签名不变→上层 touch_session/坐标映射/会话机零改动**（T-13 映射断言原样=回归锚）；
2. 引脚重配：PD12=I2C4_SCL、PD13=I2C4_SDA（AF4，清单 F2 实锤的天然匹配）；FT_RST(PH6)/INT(PH7) 逻辑与时序原样；
3. 时钟决策矩阵：首选 **400kHz**（官方 ft5x06 组件默认档）；信号完整性异常→退 **100kHz**（bit-bang 现速）；两档编译宏 `FT5446_I2C_FAST` 切换，决策记录入结果文档；
4. **旧 bit-bang 实现保留一个版本期**（`FT5446_BITBANG` 编译开关），新旧 A/B 对拍（同屏同点读数一致 ≥20 点）后下版删除；
5. I2C4 时钟源配置（HAL_I2C_MspInit：kernel clock 选择+时序参数按 CubeH7 官方 400k/100k 计算口径）。
**回归门禁（全绿才算完）**：touch_session 358 断言重跑（L1，防联动改动）→ 20 击 raw 注入全中+K4b 滑条专项+双浸泡 30min 幽灵=0（L3）→ T-12 perf：touch_gap 预算内+**单次读取时延实测对比 bit-bang（记录改善数字）**（L3）→ E-01 触摸全链 ≤1s 复跑（L3）→ P-4 主页/调参页实拍双轨（L4）。
**回退**：编译开关切回 bit-bang。**找茬锚点**：400k 下长杜邦线读数稳定性（连续 10min NAK 计数）/INT 轮询与 I2C 阻塞时长 Worst-case 重测/上电首读时序。

### W2 websocket.c 上行 JSON 统一 cJSON（前置=无；窗口=随 R2-H743 会话顺带）

### W3 comm.c txq 官方化（两阶段；阶段 A 前置=无，阶段 B 前置=A 判 GO；窗口=R3 前）
**阶段 A（评估决策，纯文档）**：产出 `docs/results/W3_txq_评估.md`——
- 语义映射表：txq 六操作（push/push_front 队头插队/poll/count/满丢老/临界保护）× 官方候选（**MessageBuffer**=官方项语义帧缓冲 ｜ StreamBuffer=字节流（项界丢失，次选）｜ esp_ringbuf=清单已证语义不符）；
- **push_front（急停优先）无官方直接等价**→官方设计模式=**双通道**（高优先 MessageBuffer+常规 MessageBuffer，消费端先高后低）；
- **Q5 保护策略**（关键）：comm.c 双端同文件——**可移植缺省实现保留现环形**（H743 裸机/PC 单测无 FreeRTOS，CMSIS/HAL 无官方队列原语=查证记录注释）+ **ESP32 侧经函数表注入官方原语后端**；文件两端同步改→md5 门禁保持；
- GO/NO-GO 判据：若官方化使急停时序（E-04 ≤500ms）劣化、或注入层破坏可移植性/单测可跑性 → **NO-GO 留档**（清单 F7 标结论，不强行——质量优先于"官方化率"）。
**阶段 B（若 GO）**：ESP32 后端实现+双端文件同步；**回归**：PC ARQ 单测+LPBK 4 项+双板 E-04（急停时序不劣化，L3+P-3 慢动作实测）/E-09/E-10+72h 浸泡窗口 txq 水位观察。**找茬**：ISR 上下文发送路径（ESP32 侧链路 RX 任务上下文=非 ISR，映射表须逐调用点证明）/高优先通道饿死常规帧的反例测试。
