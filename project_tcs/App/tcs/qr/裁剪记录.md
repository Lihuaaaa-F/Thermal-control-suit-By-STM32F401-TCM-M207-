# qrcodegen 第三方引入裁剪记录（H13，§1 第三方库引入对照条款）

- 上游：nayuki/QR-Code-generator C 版（vendor 快照 2026-10-19，qrcodegen.c 1027 行/.h 385 行）
- 用途：仅 `qrcodegen_encodeText()` BYTE 模式编码 "http://192.168.4.1"（ECC M，版本自动 2~3）
- **裁剪内容**：移除 ECI 段支持共 3 处代码 + makeEci/声明：
  1. `getTotalBits()` 的 ECI 分支
  2. `qrcodegen_makeEci()` 整函数（-1114B）
  3. `numCharCountBits()` 的 ECI case
  4. 头文件 `qrcodegen_Mode_ECI=0x7` 枚举与 makeEci 声明（枚举显式赋值 0x1/0x2/0x4/0x8，移除不移义）
- 保留：NUMERIC/ALPHANUMERIC/BYTE/KANJI 全部算法表与渲染路径（算法核心未动，降低裁剪风险）
- 许可证：MIT（LICENSE 文件随目录入 git）
- **最小渲染验证**：tests/test_qr.c 编码 → PBM 出图 → tools/qr_verify.py(zxing-cpp) 解码回读比对；
